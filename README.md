# 🇩🇪 Germany OS

> 建立德国最大的中文知识平台。

---

# 项目定位

Germany OS 不是一个小红书账号。

也不是一个网站。

更不是一个 AI。

Germany OS 是一个围绕德国留学、德国生活、德国工作的知识操作系统（Knowledge Operating System）。

未来所有内容都围绕同一个数据库进行管理。

---

# 项目使命（Mission）

帮助中文用户解决德国相关的所有问题。

包括：

- 🏠 租房
- 🎓 大学（LMU / TUM）
- 📄 APS
- 🛂 签证
- 💼 找工作
- 🛒 德国生活
- 🚇 交通
- ⚖️ 法律法规
- 🧰 实用工具

---

# 核心理念

**内容不是一次性发布，而是长期资产。**

每完成一篇内容，都应该能够用于：

- 小红书
- 网站
- Google SEO
- AI 知识库
- PDF
- 数字产品

遵循：

> **一次创作，多次使用（Build Once, Publish Everywhere）**
