# 0010 Moving

搬家不是“把东西搬过去”这么简单。德国换房时，除了搬家具，还要处理 **Anmeldung、Strom、Internet、钥匙、地址变更和旧房退租**。

这篇按搬家前 → 搬家当天 → 搬家后，把最常见的事情整理一下。

## 1. 搬家前先处理什么？

确定新房后，可以提前安排：

- Mietvertrag
- Kaution
- 搬家公司或租车
- Strom
- Internet
- 家具和家电
- 搬家日期
- 旧房 Kündigung

如果旧房还没结束租期，要先确认 Kündigungsfrist 和实际退租日期，不要因为新房已经签了合同就默认旧房可以马上结束。

## 2. 搬家前检查新房

入住前最好确认：

- 房屋有没有明显损坏
- 家具、厨房和家电是否完整
- 钥匙数量
- Zählerstände
- Keller / Stellplatz 是否属于房屋
- Strom 和 Internet 是否需要自己办理

最好提前拍照或录像，尤其是墙面、地板、门窗、厨房和卫生间。

具体交接可以看 [0015 Handover](0015_Handover.md)。

## 3. Strom 要不要重新签？

如果新房的电费不是包含在租金里，通常需要自己安排 Strom。

搬家时要记录：

- 旧房的 Zählerstand
- 新房的 Zählerstand
- Zählernummer
- Einzugsdatum / Auszugsdatum

如果更换地址后继续使用原来的 Stromanbieter，也要及时通知对方搬家。

## 4. Internet

如果新房需要自己办理 Internet，最好提前检查：

- DSL
- Kabel
- Glasfaser
- LTE / 5G

新地址是否有对应网络覆盖，以及安装是否需要预约。

如果原来的 Internet 合同可以迁移，可以向 Anbieter 申请 Umzug，而不是直接重新签一份合同。

## 5. Anmeldung

搬到新地址后，如果需要办理住址登记，就要处理 Anmeldung。

通常需要：

- Reisepass / Personalausweis
- Wohnungsgeberbestätigung
- 其他当地要求的材料

具体流程见 [0006 Anmeldung](0006_Anmeldung.md)。

## 6. 地址也要记得更新

搬家后，很多地方都需要更新地址，例如：

- 银行
- Krankenkasse
- Universität
- Arbeitgeber
- Versicherungen
- 手机和 Internet Anbieter
- 其他重要合同

也可以检查自己的 Online-Shop、会员和其他重要账户是否保存了旧地址。

## 7. 搬家当天

搬家当天最好准备：

- Mietvertrag
- Schlüssel
- Übergabeprotokoll
- 手机
- 充电器
- 重要证件
- 清洁用品
- 基本生活用品

如果是新房入住，记录水、电、暖气等相关 Zählerstände，并拍照保存。

如果是旧房退租，也要记录退房时的房屋状态和 Zählerstände。

## 8. 旧房退租

退租时重点处理：

- Kündigung
- 剩余房租
- Nebenkosten
- Kaution
- Schlüssel
- Übergabe
- Zählerstände
- 其他家具或物品

如果合同规定需要恢复某些状态，也要提前确认。

不要只把钥匙交出去就结束了，最好保留 Übergabeprotokoll 和相关照片。

## 9. 搬家后的 Kaution

旧房 Kaution 不一定在交钥匙当天退还。

房东可能需要先确认：

- 有没有未付租金
- 房屋有没有需要承担的损坏
- 有没有其他 Forderungen
- Nebenkosten 是否还需要结算

具体可以看 [0005 Kaution](0005_Kaution.md)。

## 10. 搬家费用

第一次搬家很容易低估一次性支出。

可能包括：

- 搬家公司
- 租车
- Kaution
- 家具
- 家电
- 灯具
- 清洁用品
- 安装费用
- 新房需要购买的生活用品

所以最好把“一次性搬家成本”和“每月住房成本”分开计算。

## 11. 搬家时最容易忘记的几件事

可以直接保存这个清单：

- [ ] 新房 Mietvertrag
- [ ] Kaution
- [ ] 搬家公司 / 租车
- [ ] Strom
- [ ] Internet

- [ ] 旧房 Kündigung
