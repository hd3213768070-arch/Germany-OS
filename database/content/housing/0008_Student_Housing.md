# 0008 Student Housing

如果你是学生，在德国找房不一定非要和普通租房市场硬拼。除了普通 Wohnung 和 WG，还有专门面向学生的 Studentenwohnheim。

这篇主要讲学生宿舍有哪些类型、怎么申请、住进去前要注意什么，以及它和普通租房有什么区别。

## 1. Studentenwohnheim 是什么？

Studentenwohnheim 就是学生宿舍，通常面向在德国高校就读的学生。常见提供方包括：

- **Studierendenwerk / Studentenwerk**
- 大学或其他教育机构
- 私人学生公寓运营商
- 其他住房机构

不同宿舍的申请条件、价格、房型和合同都不一样。

## 2. 学生宿舍一般有哪些房型？

- **Einzelzimmer**：单人房
- **WG-Zimmer**：合租中的独立房间
- **Einzimmerwohnung**：单人独立公寓
- **Apartment**：通常包含自己的卫生间和小厨房
- 多人共享厨房或卫生间的房型

有些宿舍家具齐全，有些则需要自己购买家具。

## 3. Studentenwerk 和私人学生公寓

这两类学生住房不要混在一起看。

### Studierendenwerk

通常属于大学所在地的学生服务体系。特点：

- 租金相对有竞争力
- 主要面向学生
- 申请人数可能很多
- 经常存在等待名单
- 有明确的申请条件

### 私人 Studentenwohnheim

由私人公司或其他机构运营。通常：

- 房型比较新
- 家具配置可能更完整
- 配套设施可能更多
- 租金和合同条件差异较大

具体价格和申请方式要看运营方。

## 4. 学生宿舍怎么申请？

通常需要先查看运营方的申请条件和申请时间。需要：

- Immatrikulationsbescheinigung
- Zulassungsbescheid
- 学生证或其他在读证明
- Reisepass / Personalausweis
- Aufenthaltstitel
- 其他个人资料

有些宿舍可以提前申请，有些需要已经获得大学录取或完成注册。

❗️❗️❗️**不要等开学后才开始找。** 热门城市的学生宿舍可能需要等待较长时间。

## 5. 等待名单

很多学生宿舍不是“申请后马上入住”，而是需要排队。

你可能会遇到 Bewerbung → Warteliste → Wohnungsangebot → Mietvertrag

所以申请多个合适的学生宿舍通常比只等一个选择更多。具体是否有 Warteliste、怎么排序，由各个运营方自行规定。

## 6. 学生宿舍的租金

学生宿舍通常会把部分费用直接包含在月租里，但具体情况不同。申请时要确认：

- Kaltmiete
- Nebenkosten
- Heizkosten
- Strom
- Internet
- Rundfunkbeitrag
- Kaution
- 家具费用
- 其他服务费

不要只比较一个月租数字。

## 7. 合同期限要特别看

学生宿舍的合同可能和普通私人租房不太一样。例如可能存在：

- 固定期限
- 最短租期
- 最长居住期限
- 学生身份要求
- 退学或毕业后的搬离要求

签合同前一定要确认自己最多可以住多久，以及毕业后还能不能继续住。

## 8. Anmeldung

学生宿舍如果属于正常 Wohnraum，也涉及 Anmeldung。入住后需要确认：

- 是否可以 Anmeldung
- 谁提供 Wohnungsgeberbestätigung
- Einzugsdatum
- 是否需要自己预约 Bürgeramt

不要因为是学生宿舍，就默认 Anmeldung 会自动完成。

具体流程见 [0006 Anmeldung](0006_Anmeldung.md)。

## 9. 学生宿舍和普通 WG 怎么选？

可以简单比较：

| | Studentenwohnheim | WG |
|---|---|---|
| 主要对象 | 学生 | 学生、年轻人等 |
| 房源 | 通常由运营方提供 | 房东或现有室友提供 |
| 申请 | 通常走官方/运营方流程 | 经常需要直接联系房东或 WG |
| 竞争 | 热门宿舍可能很激烈 | 热门城市也可能很激烈 |
| 室友 | 通常是其他学生 | 不一定都是学生 |
| 合同 | 由宿舍运营方提供 | 形式比较多 |
| 生活方式 | 规则通常比较明确 | 不同 WG 差异很大 |

## 10. 申请学生宿舍时要注意

看到合适的宿舍，可以提前确认：

- 谁可以申请
- 是否必须是学生
- 申请什么时候开放
- 是否有 Warteliste
- 最短和最长租期
- Kaution
- 是否带家具
- 是否可以 Anmeldung
- 是否允许养宠物
- Kündigungsfrist
- 毕业后是否必须搬走

尤其是合同期限和学生身份要求，最好在申请前就看清楚。
