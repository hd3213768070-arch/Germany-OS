# 0016｜德国租房诈骗：常见套路和避坑方法

德国租房市场竞争激烈，尤其是慕尼黑、柏林、汉堡等城市。房源越难找，越容易有人利用“低价房源”“急租”“人在国外”等理由催你付款。

看到特别合适的房子时，先别急着转账。租房诈骗很多时候并不是房子看起来有多假，而是对方一直催你在没有核实清楚之前付款。

## 1. 常见的租房诈骗信号

### 房租明显低于市场价格

如果一套房的位置、面积和装修都很好，但租金明显低于周围类似房源，需要提高警惕。

便宜本身不能证明是诈骗，但如果同时出现其他异常情况，就应该进一步核实。

### 房东说自己人在国外

比较常见的说法是：

- 房东现在人在国外
- 因为工作长期不在德国
- 无法亲自带你看房
- 可以通过快递寄钥匙
- 可以通过 Airbnb 或其他第三方完成交易

这些说法本身不一定代表诈骗，但如果对方以此为理由拒绝正常看房，同时要求你提前付款，需要特别小心。

### 没看房就要求付款

例如：

- 先交 Kaution 才能看房
- 先交第一个月房租才能拿钥匙
- 先支付“预订费”
- 先转账才能保留房源

尤其是还没有核实出租人身份、没有正式 Mietvertrag 的情况下，不要因为对方催促就转账。

### 要求通过私人账户或特殊方式付款

如果对方要求：

- 转到与出租人身份不匹配的账户
- 使用现金
- 购买礼品卡
- 使用加密货币
- 通过无法追回的方式付款

都应该提高警惕。正常租房应该能够明确确认收款方是谁，以及付款依据是什么。

## 2. “先付款，钥匙寄给你”要特别小心

比较常见的诈骗套路是: 对方告诉你自己不在德国 → 不能带你看房 → 让你先付款 → 承诺把钥匙寄给你。

有时还会制作一个看起来很正规的 Mietvertrag，甚至发送护照、身份证或者房屋照片。

这些东西本身都不能证明对方就是房东。如果无法正常看房，也无法独立确认出租人身份和房屋情况，不要仅仅因为对方提供了文件就付款。

## 3. 看房时也不能完全放松

能够看房，风险会降低，但也不代表一定安全。看房时可以确认：

- 房屋地址
- 房屋实际情况
- 对方身份
- 对方是否有权出租房屋
- Mietvertrag 中的出租人是谁
- Kaution 和房租支付给谁

如果对方只是带你看了一次房，然后马上要求当天支付大额款项，也不要因为“已经看过房”就完全放松警惕。

## 4. 核实出租人

在付款之前，至少应该弄清楚 **谁是房东？谁和你签合同？钱最终支付给谁？**

如果出租人是房东本人，可以核对相关身份和房屋信息。

如果是 Hausverwaltung、Wohnungsbaugesellschaft 或 Makler，则可以通过其官方联系方式独立确认。

不要只使用对方发给你的联系方式。例如，对方声称自己是某 Hausverwaltung，可以自己找到该公司的官方网站，再通过官网上的联系方式确认房源。

## 5. Untermiete 也要注意

诈骗不只发生在普通 Wohnung。WG、Untermiete 和 Zwischenmiete 同样可能出现问题。

如果对方声称自己是 Hauptmieter，需要注意：

- 对方是否真的住在这套房里
- 是否有权进行 Untermiete
- 是否需要房东同意
- 是否可以提供 Wohnungsgeberbestätigung
- Untermietvertrag 的内容是否清楚

不要因为对方说“我就是 Hauptmieter”就直接相信。

具体可以看：[0014｜Nachmieter 与 Untermiete](0014_Nachmieter_and_Subletting.md)

## 6. 注意房源照片和文字

如果同一套房子的照片出现在不同平台、不同城市或者不同价格的房源中，需要进一步核实。也可以检查：

- 房源地址是否真实
- 房屋照片是否前后一致
- 房源信息是否存在明显矛盾
- 联系人的姓名是否一致
- 租金、面积和房屋情况是否合理

如果发现大量信息对不上，不要急着申请或者付款。

## 7. 不要因为竞争激烈就失去判断

热门城市找房时，经常会遇到：“今天不付款就给别人了。” “现在有很多人申请。” “马上转 Kaution，我就给你留房。”

这种情况下最容易因为怕错过房源而忽略风险。正常的租房竞争并不意味着你必须在没有核实清楚的情况下付款。

宁愿花一点时间确认出租人、合同和付款信息，也不要因为着急抢房而直接转账。

## 8. 个人资料也要注意保护

租房申请确实可能需要提供：

- Reisepass
- Aufenthaltstitel
- SCHUFA
- Gehaltsabrechnungen
- Arbeitsvertrag
- Kontoauszüge

但这些都是个人重要资料。

不要为了申请一套还没有确认真实性的房子，就把所有材料无条件发送给陌生人。尤其是完整银行流水、身份证件和其他与租房无关的个人信息，可以根据实际需要进行保护或遮挡。

SCHUFA 的具体注意事项可以看：[0013｜SCHUFA 与德国租房](0013_SCHUFA_for_Renting.md)

## 9. 看到可疑房源怎么办？

如果觉得一个房源可能有问题，可以先暂停付款和提交更多个人资料。然后重新确认：

1. 房源地址是否真实
2. 出租人是谁
3. 对方是否有权出租
4. Mietvertrag 是否合理
5. Kaution 和房租应该支付给谁
6. 房东或 Hausverwaltung 是否可以通过独立渠道确认
7. 房源是否同时出现在其他平台

如果对方拒绝合理核实，或者不断催促付款，就不要继续进行交易。

## 10. 已经付款了怎么办？

如果已经怀疑自己遇到了租房诈骗，不要继续等待对方。可以尽快：

- 联系银行，询问是否还能取消或追回转账
- 保存聊天记录
- 保存房源截图
- 保存 Mietvertrag 和其他文件
- 保存付款凭证
- 保存对方的姓名、账户信息和联系方式
- 向警方报案
- 如果涉及平台交易，也向对应平台举报

越早处理，越容易保留完整证据。

## 11. 租房前的简单检查

准备付款前，可以快速检查：

- [ ] 已经确认房源真实存在
- [ ] 已经确认出租人身份
- [ ] 确认对方有权出租房屋
- [ ] 已经看过房，或者能够通过可靠方式核实房源
- [ ] 已经确认 Mietvertrag
- [ ] 已经确认 Kaltmiete、Nebenkosten 和 Warmmiete
- [ ] 已经确认 Kaution
- [ ] 已经确认付款对象和账户
- [ ] 没有被要求通过异常方式付款
- [ ] 没有因为“马上有人抢”而被迫仓促付款

## 12. 最容易记住的一条

如果一个租房交易同时出现：**价格异常便宜 + 无法正常看房 + 出租人身份无法确认 + 要求提前付款** 就不要急着交钱。

德国正常租房也会有竞争，但竞争激烈不等于可以跳过基本的核实过程。
