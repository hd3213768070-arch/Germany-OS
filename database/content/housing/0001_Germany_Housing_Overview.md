# 0001 Germany Housing Overview

第一次在德国租房，最容易搞不清的就是 **Kaltmiete、Warmmiete、Kaution**，还有到底要准备哪些材料。

OMA在这把德国租房的基本框架讲清楚：德国有哪些常见住房、租房会花哪些钱、申请时要准备什么，以及从找房到入住大概怎么走。

## 1. 德国常见住房类型

德国租房不只有公寓，常见的还有：

- **Wohnung**：普通楼房
- **WG**：和其他人合租
- **Studentenwohnheim**：学生宿舍
- **Zwischenmiete**：短期或过渡性租房
- **Untermiete**：转租
- **Einfamilienhaus / Reihenhaus**：独栋住宅、联排住宅

学生最常遇到的通常是 Wohnung、WG 和 Studentenwohnheim。

## 2. 租房时会遇到哪些费用？

看德国房源时，经常会看到这些词：

- **Kaltmiete**：基础租金，不包含部分附加费用
- **Nebenkosten**：房屋运营等附加费用
- **Warmmiete**：通常是 Kaltmiete 加上 Nebenkosten
- **Kaution**：押金
- **Strom**：电费，有些房子需要自己单独签合同
- **Internet**：网络费用
- **Rundfunkbeitrag**：广播电视费
- **Stellplatz**：停车位，可能另外收费

具体包含哪些费用，要看房源和 Mietvertrag，不能只看 Warmmiete 一个数字。

## 3. 租房申请一般要准备什么？

德国租房竞争比较激烈，房东或中介可能会要求一整套材料，例如：

- Reisepass / Personalausweis
- Aufenthaltstitel
- SCHUFA
- Einkommensnachweis
- Arbeitsvertrag
- Mieterselbstauskunft
- Immatrikulationsbescheinigung
- Bürgschaft

不一定每个房东都要求全部材料，具体看房源和对方的要求。

## 4. 从找房到入住，大概经历什么？

德国租房一般可以理解成：Wohnung suchen → Besichtigung → Bewerbung → Zusage → Mietvertrag → Kaution → Übergabe → Einzug

签完合同、完成交接后，入住还可能涉及 **Anmeldung、Strom、Internet** 等手续。

## 5. 租房时最容易踩坑的地方

有几个地方建议从一开始就看清楚：

- **Mietvertrag**：租期、租金、Kündigungsfrist 等条款
- **Kosten**：Warmmiete 到底包含什么，还有哪些费用要自己支付
- **Kaution**：金额、支付方式以及退还条件
- **Wohnungsübergabe**：入住时把房屋状况、钥匙数量和 Zählerstände 记录清楚
- **房源真实性**：还没看房就要求你转账，尤其要警惕
