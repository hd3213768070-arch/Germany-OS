# 0011｜德国租房平台：Wohnung、WG、学生房分别去哪里找？

在德国找房，不是只有 ImmoScout24 一个网站。普通 Wohnung、WG、Zwischenmiete、Studentenwohnheim 经常分布在不同平台上。

这篇主要介绍德国常见租房平台：每个平台适合找什么、有什么优势和不足，以及使用时需要注意什么。

## 1. ImmoScout24

[ImmoScout24](https://www.immobilienscout24.de/) 是德国最主要的房地产平台之一，普通 Mietwohnung、Haus、WG、Wohnen auf Zeit、Stellplatz 等都有。

**适合找：**
- 普通 Wohnung
- 1–4 Zimmer 等长期租房
- Neubau
- Haus
- Stellplatz
- 部分 WG 和短租

**优势**
- 房源数量大，覆盖城市广
- 筛选条件比较完整，可以按价格、面积、房间数、入住时间和区域筛选
- 可以设置 Suchauftrag，新房源出现后接收提醒
- 房源信息通常比较完整，适合长期租房

**劣势**
- 热门城市竞争激烈
- 好房源可能发布后很快收到大量申请
- 部分功能需要付费会员
- 同一套房可能同时出现在多个平台

**注意**
- 不要在没有核实房源和出租人身份前支付 Kaution 或房租
- 联系房东前先确认房源地址、租金构成、入住时间和出租人身份
- 注意区分 `Kaltmiete`、`Warmmiete` 和其他额外费用
- 如果对方要求看房前付款，要特别警惕

## 2. Immowelt

[Immowelt](https://www.immowelt.de/) 也是德国大型房地产平台，房源包括 Wohnung、Haus、Wohnen auf Zeit、WG、Garage/Stellplatz 和 Neubau 项目等。

**适合找：**
- 普通 Wohnung
- Haus
- Neubau
- Wohnen auf Zeit
- WG
- Stellplatz

**优势**
- 房源覆盖范围广
- 和 ImmoScout24 的房源并不完全一样，可以作为第二个主要平台
- 筛选功能比较完善
- 适合长期租房和商业房源

**劣势**
- 热门城市同样竞争激烈
- 部分房源可能同时出现在其他平台
- 房源质量取决于具体出租方，不能因为是大型平台就默认安全

**注意**
- 不要只看首页推荐，可以自己设置具体区域和价格条件
- 仔细看 `Nebenkosten` 是否已经包含在 `Warmmiete` 中
- 注意房源是不是 `Nachmieter`、`Untermiete` 或 `Wohnen auf Zeit`
- 看清楚出租方是私人房东、Hausverwaltung 还是中介

## 3. Kleinanzeigen

[Kleinanzeigen](https://www.kleinanzeigen.de/) 不只是租房网站，而是德国大型分类信息平台。租房板块里经常能看到私人房东发布的 Wohnung、WG、Zwischenmiete、Nachmieter 等信息。

**适合找：**
- 私人房东
- WG
- Zwischenmiete
- Nachmieter
- Untermiete
- 家具和搬家相关物品

**优势**
- 房源类型非常多
- 私人房东发布的房源比较多
- 有时能找到其他房地产平台没有的房子
- 不仅能找长期租房，也适合找短租

**劣势**
- 房源质量差异很大
- 房源信息可能不完整
- 私人出租的沟通质量差异很大
- 需要特别注意虚假房源和诈骗

**注意**
- **不要在没有看房、没有核实出租人身份的情况下付款**
- “人在国外”“钥匙通过快递寄给你”“先交押金才能看房”等说法要特别警惕
- 房租明显低于同区域正常水平时要多核实
- 看清楚是不是 `Untermiete`，以及 Hauptmieter 是否获得房东同意
- 尽量保留完整的聊天记录和房源信息

## 4. WG-Gesucht

[WG-Gesucht](https://www.wg-gesucht.de/) 最初主要用于 WG-Zimmer，但现在也有大量普通 Mietwohnung。

**适合找：**
- WG-Zimmer
- WG
- Zwischenmiete
- Untermiete
- Nachmieter
- 1-Zimmer-Wohnung
- 短期租房
- 部分普通 Wohnung

**优势**
- WG 房源非常多
- 学生使用非常普遍
- `Zwischenmiete`、`Untermiete` 等短期房源比较丰富
- 可以直接联系 WG 成员、Hauptmieter 或房东
- 对刚到德国、暂时没有长期住房的人比较方便

**劣势**
- 很多房源竞争很大
- WG 往往不仅看材料，还可能有 `WG-Casting`
- 房源类型比较复杂，合同关系容易看不懂
- 有些房源只适合短期入住

**注意**
- 一定确认自己签的是 `Mietvertrag` 还是 `Untermietvertrag`
- 问清楚谁是 Hauptmieter、谁负责 Anmeldung
- 确认 `Warmmiete` 是否包含 Strom、Internet 等费用
- 如果是 Untermiete，最好确认 Hauptmieter 是否获得房东同意
- 提前问清楚入住期限、Kaution、家具和退租条件

## 5. Studentenwerk / Studierendenwerk

如果你是学生，还可以直接看所在城市的 Studierendenwerk。

德国各地的 Studierendenwerke 会管理 Studentenwohnheime，申请通常不是通过普通房地产平台，而是进入对应城市的 Studierendenwerk 网站申请。

**适合找：**
- Studentenwohnheim
- 学生宿舍
- 学生公寓
- 部分学生专项住房

**优势**
- 专门面向学生
- 房租通常比较适合学生预算
- 申请和入住规则相对明确
- 不需要完全按照普通私人租房市场的方式寻找房源

**劣势**
- 房源数量有限
- 热门城市可能需要等待较长时间
- 房间面积通常比较小
- 合同期限、续租规则可能比较严格
- 不一定能选择自己想要的区域或房型

**注意**
- 很多 Studentenwohnheim 需要提前申请，不是“有房再申请”
- 不同城市的申请规则可能完全不同
- 注意 `Warteliste`、申请截止时间和 Studentenstatus 要求
- 拿到房间后也要确认是否可以 Anmeldung、合同期限以及退租规则

## 6. Wohnungsbaugesellschaft / Wohnungsgenossenschaft

很多房子并不会只放在 ImmoScout24 等平台上，而是由当地的 Wohnungsbaugesellschaft 或 Wohnungsgenossenschaft 自己出租。

这类机构一般会在自己的官网发布房源，有些还需要提前登记或申请会员。

**适合找：**
- 长期 Wohnung
- 普通住宅

**优势**
- 很多房源由机构直接管理
- 比私人临时出租更适合长期居住
- 部分机构会长期维护自己的房源池
- 某些房源不会全部放到大型租房平台

**劣势**
- 房源更新速度可能比较慢
- 热门城市申请人数多
- 部分 Genossenschaft 需要购买 `Genossenschaftsanteile`
- 有些房源有特定资格要求

**注意**
- `Wohnungsgenossenschaft` 和普通房东不是一回事
- 入住前要搞清楚自己购买的是不是 `Genossenschaftsanteile`
- 不要把 `Genossenschaftsanteile` 和普通 `Kaution` 混为一谈
- 看清楚退出合作社后股份怎么处理
- 关注当地机构官网，不要只等 ImmoScout24 上的房源

## 7. 常见平台怎么搭配？

如果你找的是**普通长期 Wohnung**，可以重点看：

`ImmoScout24 + Immowelt + Kleinanzeigen`

如果你找的是**WG 或短租**：

`WG-Gesucht + Kleinanzeigen`

如果你是**学生，预算比较有限**：

`Studierendenwerk + WG-Gesucht`

如果你找的是**长期住宅，而且不急着马上入住**：

`ImmoScout24 + Immowelt + 当地 Wohnungsbaugesellschaft / Wohnungsgenossenschaft`

不同平台的房源并不完全重复，所以不要只盯着一个网站。
