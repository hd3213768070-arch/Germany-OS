# 🔄 0005｜德国退货与退款指南 Returns and Refunds in Germany

> 在德国买错东西、网购后不喜欢、衣服尺码不合适、商品有质量问题，分别应该怎么处理？网购真的可以14天无理由退货吗？实体店买的商品能退吗？商家迟迟不退款怎么办？
>
> 本文介绍德国购物中的退货、撤销合同、退款、换货及商品质量问题处理方式，帮助留学生和新居民了解自己的消费者权益，避免因不了解规则而产生不必要的损失。

---

## 🧭 一、先弄清楚：你遇到的是哪一种情况？

德国的退货规则会因购买方式、商品情况和交易类型而不同。

**最重要的区别是：商品没有质量问题，只是你不想要了；还是商品本身存在问题。**

| 你的情况 | 通常需要了解的规则 |
|---|---|
| 实体店购买，商品没有质量问题 | 商家的自愿退换货政策 |
| 网购后改变主意 | 法定撤销权 Widerrufsrecht 是否适用 |
| 商品损坏或与合同约定不符 | 法定瑕疵责任 Gewährleistung |
| 商品在商家承诺的保证期内出现问题 | 商业保证 Garantie 的具体条款 |
| 已经退货，但迟迟没有退款 | 退款规则、退货凭证及付款方式 |
| 包裹未收到 | 实际交付情况及相关法律责任 |
| 收到错误商品 | 合同约定、卖家责任及相应救济 |
| 私人二手交易发生纠纷 | 私人交易规则及具体约定 |

这几种情况不能一概按照“14天退货”处理。

## 🏪 二、德国实体店买的东西可以退吗？

### 1. 商品没有质量问题，只是改变主意

例如：

- 买回家的衣服觉得不好看。
- 买错了颜色或尺码。
- 回家后发现不需要这件商品。
- 看到其他商店有更便宜的价格。
- 买完后改变了主意。

对于在德国实体店购买、没有质量问题的商品，商家通常**没有必须接受退货的普遍法定义务**。

是否允许退货、换货或退款，通常取决于商家自己的政策。

### 2. 商家可能提供哪些退货方式？

| 德语 | 中文 | 说明 |
|---|---|---|
| Rückgabe | 退回商品 | 泛指退货 |
| Umtausch | 换货 | 更换商品、尺码或颜色 |
| Rückerstattung | 退款 | 退还已支付的金额 |
| Gutschein | 购物券 | 商家可能提供的替代方案 |
| Rückgabefrist | 退货期限 | 商家规定的退货时间 |
| Originalverpackung | 原包装 | 商品原有包装 |
| Kassenbon | 收银小票 | 购买凭证 |

商家可能规定：

- 14天、30天或其他退货期限。
- 必须提供小票。
- 商品必须保持未使用状态。
- 某些商品不能退。
- 只能换货或获得购物券。
- 必须在原购买门店或指定渠道办理。

这些都是可能出现的商家政策，并不代表所有德国商店都采用相同规则。

### 3. 退货时需要带什么？

建议准备：

1. 商品本身。
2. 购买小票 Kassenbon 或其他购买凭证。
3. 原包装及配件（如果有）。
4. 付款记录（必要时）。
5. 会员卡或订单信息（如果适用）。

如果小票丢失，可以询问商家是否接受银行卡交易记录或其他购买证明。但商家是否愿意按自愿退货政策受理，仍要看其具体规定。

### 4. 实体店买到有质量问题的商品怎么办？

如果商品存在瑕疵，不应只按照普通退货政策处理。

这种情况可能涉及法定瑕疵责任 Gewährleistung。即使商家不接受“改变主意式退货”，也不意味着它可以不处理依法应承担的商品质量责任。

具体处理方式见本文第七部分。

## 📦 三、德国网购的14天撤销权是什么？

德国和欧盟消费者保护规则对符合条件的远程销售合同设有撤销权，德语为 **Widerrufsrecht**。

对于许多消费者通过网站或其他远程方式与商家订立的商品销售合同，通常可以在法定期限内撤销合同，而不需要说明理由。

但需要注意：

- 并不是所有交易都适用。
- 法律规定了若干例外。
- 撤销权与商品有质量问题时的权利不同。
- 商家自愿提供的退货政策可能比法定最低要求更宽松。

### 1. 14天从什么时候开始算？

对于许多普通商品销售合同，撤销期限通常从消费者或其指定的第三方（承运人除外）实际收到商品之日起计算。

因此，通常不能简单地把下单日、付款日或发货日当作所有网购订单的统一起算日。

如果订单分批交付、包含多件商品或属于特殊类型的合同，可能适用不同的计算方式。

如果商家没有依法履行有关撤销权的告知义务，期限也可能受到影响。

### 2. 如何行使撤销权？

通常可以按照以下步骤操作：

**第一步：找到商家的撤销说明。**

在订单详情、邮件、网站或相关条款中寻找：

- Widerrufsrecht
- Widerrufsbelehrung
- Muster-Widerrufsformular

**第二步：向商家明确表示撤销合同。**

可以通过电子邮件或商家提供的在线流程发送撤销声明。建议使用可以保存记录的方式。

**第三步：保存发送凭证。**

保存邮件、在线提交确认、订单编号和发送时间。

**第四步：按照要求寄回商品。**

查看商家的退货地址、退货标签和寄回说明。

**第五步：保存退货凭证。**

保留退货运单号和投递凭证，以便查询物流状态。

### 3. 只把商品寄回去就可以了吗？

不建议只寄回商品而不说明撤销合同的意思。

为了避免争议，最好在期限内明确通知商家撤销合同，再按照相关要求寄回商品。

**退货寄回和撤销合同是相关但不完全相同的步骤。**

### 4. 撤销合同一定要使用商家的表格吗？

通常不一定。

在适用法定撤销权的情况下，消费者一般需要向商家明确表达撤销合同的决定，但通常不必使用特定格式。

商家提供的 Muster-Widerrufsformular（示范撤销表格）可以帮助你完成操作，但不应将其简单理解为所有情况下都必须使用的唯一方式。

具体仍应以适用法律和交易情况为准。

## 🚫 四、哪些网购商品可能不能按普通规则退货？

德国法律对撤销权规定了若干例外。是否适用例外，需要结合商品类型、合同内容和实际情况判断。

常见需要特别注意的类别包括：

### 1. 定制商品

按照消费者个人规格制作，或明显根据个人需求定制的商品，可能不适用普通撤销权。

例如，某些刻有个人姓名或按照特定尺寸制作的商品。

但并不是所有按订单生产的商品都自动属于例外，具体需要根据法律条件判断。

### 2. 容易迅速变质的商品

部分容易迅速变质或保质期很短的商品，可能不适用普通撤销权。

具体取决于商品性质及法律规定。

### 3. 某些已拆封的密封商品

对于因健康保护或卫生原因不适合退回、并在交付后被拆封的特定密封商品，法律可能规定撤销权例外。

但这并不意味着所有化妆品、洗护用品或拆封商品都不能退。

应根据商品类别、密封性质和适用法律判断。

### 4. 某些已拆封的软件、音像制品

对于符合特定条件、以密封形式交付并在交付后被拆封的软件或录音录像制品，可能适用撤销权例外。

具体情况应根据法律规定判断。

### 5. 已经开始履行的特定服务

部分数字内容、服务合同或其他特殊交易，在满足法定条件时，可能存在撤销权例外或权利提前终止的情况。

不能简单地认为所有数字商品、订阅或在线服务都适用相同规则。

### 6. 私人之间的二手交易

如果你通过二手平台向私人卖家购买商品，交易规则可能与向商业商家购买不同。

在符合条件的私人交易中，通常不存在适用于普通商家远程销售的同等法定撤销权。

如果商品有问题，仍需结合具体约定、卖家身份及适用法律判断。

**重要：不要仅凭“商品已经拆封”“属于打折商品”或“是二手商品”就认定自己一定没有权利。**

## 💶 五、退货运费由谁承担？

退货运费并不是所有情况下都由同一方承担。

### 1. 网购撤销合同

在适用法定撤销权的情况下，消费者可能需要承担直接退货费用，前提是商家依法履行了相关告知义务。

如果商家承诺免费退货，则应查看其承诺的具体条件。

购买前建议确认：

- 是否免费退货。
- 是否需要自行购买退货邮票。
- 是否提供免费退货标签。
- 是否需要预约上门取件。
- 大件商品是否涉及特殊运输费用。

### 2. 商品存在质量问题

如果商品存在依法应由卖家承担责任的瑕疵，相关运输或处理费用可能由卖家承担。

但具体安排取决于适用法律和实际情况。

例如，商家可能要求先联系客服，再提供退货标签或安排维修、更换。

建议在自行支付高额运输费用前，先与商家书面确认处理方式。

### 3. 实体店自愿退货

如果商品没有质量问题，只是希望按照商家政策退货，运费或其他退货条件可能由商家自行规定。

### 4. 退货前的实用建议

不要未经确认就将商品寄到普通客服地址。

先查看商家的正式退货流程，避免出现：

- 寄错地址。
- 无法识别订单。
- 退货标签不符合要求。
- 物流费用过高。
- 退货凭证不足。

## 💳 六、商家应该什么时候退款？

在符合条件的法定撤销交易中，商家通常应在收到撤销通知后14天内退还消费者应退的款项。

但是，商家通常可以在以下两个时间点中较早者到来之前暂缓退款：

- 收到退回的商品。
- 收到消费者已寄回商品的证明。

具体规则取决于交易情况及适用法律。

### 退款通常包括什么？

在适用法定撤销权的情况下，退款通常涉及消费者支付的商品价款，以及符合规定的标准配送费用。

如果消费者选择了商家提供的最便宜标准配送方式以外的额外配送服务，额外费用可能不需要退还。

具体应结合订单和适用法律判断。

### 退款会退到哪里？

通常应按照适用规则退回原付款方式，除非消费者明确同意其他方式，且相关安排符合法律要求。

例如：

- 信用卡付款：可能退回原信用卡。
- PayPal 付款：可能退回相关 PayPal 账户。
- 银行转账：需要根据商家流程确认退款账户。
- 其他支付方式：按交易和退款规则处理。

### 退款迟迟不到账怎么办？

建议按以下顺序处理：

1. 查看商家是否已确认收到退货。
2. 检查订单状态和退款通知。
3. 查看原付款账户的交易记录。
4. 联系商家，询问退款处理状态。
5. 保存退货物流、退款承诺及沟通记录。
6. 如果商家长期不处理，考虑向消费者组织咨询，或根据付款方式联系支付服务商。

不同付款方式的退款到账时间不同，银行或支付平台的处理时间也可能造成延迟。

## 🛠️ 七、商品有质量问题：Gewährleistung 与 Garantie

德国购物中，这两个概念非常重要。

### 1. Gewährleistung：法定瑕疵责任

Gewährleistung 是卖家根据法律对商品瑕疵承担的责任。

如果商品不符合合同约定，例如：

- 新买的电器无法正常工作。
- 商品收到时已经损坏。
- 商品缺少合同约定的配件。
- 商品与约定的规格不符。
- 商品存在其他依法构成瑕疵的情况。

消费者可能享有相应的法律救济。

在符合条件时，通常可以先要求补救，例如维修或更换。

如果补救未成功、被依法拒绝或存在其他法定条件，则可能进一步涉及降价、解除合同或损害赔偿等权利。

具体权利取决于实际情况，不能认为任何轻微问题都可以直接要求全额退款。

### 2. Garantie：商业保证

Garantie 通常是卖家、制造商或其他保证人自愿提供的额外保证。

其内容取决于具体保证条款，例如：

- 保证期限。
- 适用商品。
- 哪些故障属于保障范围。
- 是否要求提供购买凭证。
- 维修、更换或其他处理方式。
- 是否存在例外。

**Garantie 不能简单替代或排除消费者依法享有的强制性权利。**

即使制造商保证期已经结束，也不代表卖家依法承担的瑕疵责任必然同时结束。

### 3. 德国新商品的法定期限

对于许多消费者购买的新商品，法定瑕疵请求权通常适用两年的时效规则，起算方式一般与商品交付有关。

但不同商品、合同类型和特殊情形可能存在不同规定。

二手商品在满足法律条件时，部分法定期限可能可以通过有效约定缩短；消费者与商业卖家之间的交易还受到特别保护规则约束。

因此，不能把“两年”简单理解为所有商品、所有问题都必然可以在两年内无条件退货。

### 4. 商品出现问题后怎么办？

建议：

1. 拍摄故障、损坏或不符之处。
2. 保存订单确认和购买凭证。
3. 明确联系实际卖家。
4. 说明商品存在的问题。
5. 说明你希望采取的处理方式，例如维修或更换。
6. 保存客服回复。
7. 如有必要，查询德国消费者组织的相关建议。

更多法律信息可参考德国民法典：

https://www.gesetze-im-internet.de/bgb/

## 👕 八、衣服、鞋子和化妆品退货有什么不同？

### 1. 衣服和鞋子

如果通过符合条件的网购合同购买，通常可能适用法定撤销权。

试穿商品以判断尺码、版型和是否合适，通常不等同于任意使用商品。

但如果商品被超出必要检查范围地使用、损坏或导致价值减少，可能产生相应法律后果。

建议：

- 在室内试穿。
- 保留吊牌和包装。
- 不要穿着商品外出后再当作未使用商品退回。
- 保存退货凭证。

具体处理仍应根据商品状况和法律规定判断。

### 2. 化妆品和护肤品

化妆品的退货规则需要特别注意。

如果商品没有质量问题，能否退货可能取决于是否适用法定撤销权，以及商品是否属于法律规定的例外。

不能简单认为：

- 所有未拆封化妆品都必须接受退货。
- 所有拆封化妆品都不能退。
- 所有卫生用品都自动排除撤销权。

应结合密封状态、商品类型、法律规定及商家政策判断。

### 3. 电子产品

电子产品如果没有质量问题，退货通常取决于购买方式及适用的撤销权或商家政策。

如果产品存在故障，则可能涉及法定瑕疵责任。

建议保存：

- 原包装。
- 充电器和其他配件。
- 订单和付款记录。
- 商品序列号。
- 故障照片或视频。
- 与客服的沟通记录。

### 4. 家具和大型商品

家具退货可能涉及额外运输和搬运成本。

购买前应确认：

- 商品尺寸。
- 是否需要组装。
- 退货运输如何安排。
- 是否需要保留包装。
- 商家是否提供上门取件。
- 相关费用由谁承担。

不要因为商品体积较大，就假设法定撤销权一定不适用；也不要假设退货一定免费。

## 🛒 九、Amazon、Zalando 等平台退货时要注意什么？

不同平台的退货政策会随商品、卖家、会员权益和促销条件变化。

### 1. Amazon

购买前应查看：

- 实际卖家。
- 商品页面的退货信息。
- 订单详情中的退货选项。
- 退货标签和寄回地址。
- 退款状态。

如果商品由第三方商家销售，应确认实际卖家及相关交易条件。

### 2. Zalando

购买服装和鞋子时，应查看：

- 订单中的退货期限。
- 退货方式。
- 商品状态要求。
- 退货标签或二维码的使用方法。
- 退款处理状态。

不要直接套用其他平台的退货期限或流程。

### 3. MediaMarkt 等电子产品商家

购买电子产品时，应检查商品是否由商家自营或第三方提供，并确认相应的退货及售后政策。

如果商品存在故障，应明确说明这是质量问题，而不只是一般的改变主意式退货。

### 4. 平台订单的共同建议

无论使用哪个平台，都应保存：

- 订单编号。
- 商品页面信息。
- 付款凭证。
- 退货申请确认。
- 退货标签。
- 物流追踪号。
- 客服沟通记录。
- 退款确认。

如果平台有正式的退货入口，优先通过平台规定的流程办理。

## ⚠️ 十二、商家拒绝退货或不退款怎么办？

如果你认为商家的处理不合理，建议先明确自己依据的是什么权利。

### 情况一：实体店商品没有质量问题

先查看商家是否承诺退货或换货。

如果商家没有提供相应承诺，通常不能仅因为改变主意就要求实体店必须退款。

### 情况二：网购商品符合撤销权条件

保存撤销通知、订单信息和寄回凭证。

如果商家拒绝承认撤销，应要求其书面说明理由，并核对交易是否符合相关法律条件。

### 情况三：商品存在质量问题

明确提出商品瑕疵，并根据情况要求依法补救。

如果商家直接拒绝处理，可以进一步核实法定权利和适用期限。

### 情况四：商家已经确认退款，但迟迟没有到账

先确认商家是否完成退款操作，再向支付服务商或银行查询交易状态。

如果使用信用卡或 PayPal 等方式付款，可以询问是否存在适用的争议处理或买家保护程序。

但是否能够追回款项，取决于交易情况和相关规则。

### 可以寻求哪些帮助？

- 德国消费者组织 Verbraucherzentrale。
- 相关支付服务商或银行。
- 适用情况下的欧洲消费者中心。
- 必要时寻求法律咨询。

不要仅因为商家拒绝退款，就假设自己一定可以立即获得全额退款；也不要因为商家第一次拒绝，就认定自己完全没有法律权利。

- [ ] 阅读退货及撤销权说明。
- [ ] 确认退货费用。
- [ ] 检查是否存在法定撤销权例外。

- [ ] 检查退款状态。
- [ ] 保存客服回复。
- [ ] 退款异常时及时联系商家或支付服务商。

## ❓ 十四、常见问题 FAQ

### Q1：德国实体店买的衣服，14天内一定能退吗？

不一定。对于没有质量问题的实体店购物，商家通常没有必须接受退货的普遍法定义务。应查看商家的自愿退货政策。

### Q2：德国网购真的有14天无理由退货吗？

对于符合条件的远程销售合同，通常有14天法定撤销权，但存在法律规定的例外，具体起算时间也取决于交易类型。

### Q3：网购商品拆封后还能退吗？

不能一概而论。应根据商品类别、拆封情况、法律规定和商家政策判断。

### Q4：商家说打折商品不能退，合法吗？

要区分商品没有质量问题时的自愿退货政策，与消费者依法享有的撤销权或瑕疵责任。打折本身并不意味着消费者的所有法定权利都自动消失。

### Q5：退货运费一定由消费者承担吗？

不一定。费用分配取决于交易类型、商家的告知或承诺，以及适用法律。

### Q6：寄回商品后，商家多久应该退款？

在符合条件的法定撤销交易中，通常适用收到撤销通知后14天内退款的规则，但商家在法定条件下可以暂缓退款，直至收到商品或收到寄回证明。

### Q7：没有小票还能退货吗？

如果是实体店自愿退货，商家可能要求购买凭证。商品存在质量问题时，小票并非证明购买事实的唯一可能证据，但你需要能够合理证明交易情况。

### Q8：商品有质量问题，可以直接要求退款吗？

不一定。通常需要根据法定瑕疵责任判断是否应先维修或更换，以及是否满足进一步退款或解除合同的条件。

### Q9：商家提供的 Garantie 结束了，就不能再要求处理商品问题吗？

不一定。商业保证与法定瑕疵责任是不同的制度。应分别查看保证条款及依法适用的瑕疵责任规则。

### Q10：私人二手交易也能14天无理由退货吗？

通常不能直接套用普通商业网购的撤销权规则。私人交易需要结合卖家身份、交易约定和适用法律判断。

### Q11：退款已经显示成功，为什么银行账户还没到账？

可能与原付款方式、银行处理时间或支付平台流程有关。建议先向商家确认退款交易是否完成，再联系银行或支付服务商查询。

### Q12：商家拒绝退款，应该先找谁？

先联系实际卖家并保存书面记录。根据问题类型，可以进一步向消费者组织、银行或支付服务商咨询。
