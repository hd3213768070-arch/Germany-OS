## 🏪 二、Amazon.de 怎么买？

Amazon 是德国常见的综合网购平台之一，适合购买日用品、电子产品、书籍、家居用品及其他商品。

但需要注意：**在 Amazon 上销售的商品不一定由 Amazon 自营。**

商品可能来自平台自营业务、第三方商家或其他销售渠道。

### 1. 下单前检查什么？

建议检查以下信息：

- 商品名称和型号。
- 商品规格、容量和颜色。
- 实际卖家。
- 配送方及预计送达日期。
- 商品评价。
- 退货条件。
- 最终价格及配送费用。

对于电子产品，尤其要确认型号、插头、语言、保修适用范围和商品状态。

### 2. Sold by 和 Dispatches from 是什么意思？

在商品页面上，可能看到类似的卖家及配送信息。

| 英文 | 含义 |
|---|---|
| Sold by | 商品销售方 |
| Dispatches from | 商品发货方 |
| Amazon | 可能表示 Amazon 参与销售或配送，具体看页面信息 |
| Third-party seller | 第三方卖家 |

销售方和发货方不是同一个概念。

即使商品由 Amazon 配送，也不代表它一定由 Amazon 自营销售。

### 3. Prime 会员值得买吗？

Amazon Prime 可能提供符合条件商品的配送权益及其他会员服务。

是否值得购买，取决于：

- 你的购物频率。
- 是否经常购买符合条件的商品。
- 是否实际需要其他会员权益。
- 会员费用。
- 试用期结束后的续费规则。

开通前应检查当前会员价格、试用条件、自动续费及取消方式。

不要只因为某件商品提供 Prime 配送，就默认长期会员一定划算。

## 👗 三、德国服装网购：Zalando 等平台

德国购买服装、鞋子和配饰时，可以使用专业服装平台或品牌官方网站。

### 网购衣服需要注意什么？

#### 1. 尺码

不同品牌的尺码标准可能不同。

建议查看：

- 商品尺码表。
- 胸围、腰围和臀围。
- 鞋内长或鞋码说明。
- 商品版型。
- 用户评价中关于尺码的反馈。

不要只根据平时穿的 S、M、L 或固定鞋码下单。

#### 2. 商品照片和实际颜色

不同屏幕、拍摄光线和商品批次可能造成颜色差异。

如果颜色对你很重要，应查看商品详情和不同角度的图片。

#### 3. 退货条件

购买前应确认：

- 是否可以退货。
- 退货期限。
- 退货运费由谁承担。
- 商品是否需要保持原有状态。
- 是否需要使用指定退货标签。

**不要认为所有服装平台都提供完全相同的退货政策。**

部分商家可能提供比法律最低要求更宽松的退货服务，但具体条件以购买时的规定为准。

## 💻 四、德国电子产品网购

购买电脑、手机、显示器、家电及其他电子产品时，可以比较专业零售商、品牌官网和综合电商平台。

### 购买前检查清单

1. 商品完整型号。
2. 处理器、内存、存储容量等规格。
3. 是否为新品、翻新商品或二手商品。
4. 是否包含必要配件。
5. 电源、插头和电压要求。
6. 保修及法定瑕疵责任相关信息。
7. 配送方式和预计送达时间。
8. 退货条件。
9. 键盘布局及系统语言。
10. 是否适用于德国或欧洲市场。

### 特别注意：商品型号可能非常接近

同一产品系列可能存在多个版本。

例如，笔记本电脑可能具有相同的外观，但处理器、显卡、内存、屏幕和键盘布局不同。

购买前应核对完整型号，而不是只看商品标题中的品牌名称。

### 翻新商品和二手商品

常见词语：

| 德语或英语 | 含义 |
|---|---|
| Neu | 新品 |
| Gebraucht | 二手 |
| Refurbished | 翻新或经过整备的商品 |
| B-Ware | 通常指非标准新品销售的商品，具体状态因商家而异 |
| Wie neu | 如新，属于商品状态描述，不能代替具体检查 |

这些词语不能单独证明商品一定没有问题。

应查看商品状态、销售方说明、配件、退货条件和相关法律权利。

## 🏠 五、德国家具和家居用品网购

家具、床垫、桌椅、灯具和家居用品可以通过家具商、品牌官网及综合电商平台购买。

### 下单前必须检查

#### 1. 尺寸

仔细确认：

- 长度、宽度和高度。
- 是否需要自行组装。
- 包装尺寸。
- 门口、走廊和楼梯是否方便搬运。
- 电梯是否能够容纳商品。
- 是否需要预约送货。

对于德国公寓，尤其要考虑楼梯间较窄、没有电梯或阁楼楼梯转角较小等情况。

#### 2. 配送服务

家具配送可能分为：

- 送到楼门口。
- 送到指定楼层。
- 送入房间。
- 额外组装服务。

不同服务的价格和覆盖范围可能不同。

**不要默认家具配送一定包含搬上楼或安装。**

#### 3. 退货成本

大型家具的退货可能涉及预约、包装、搬运和运输问题。

购买前应查看商家的撤销权说明、退货流程及可能产生的费用。

如果商品需要特殊运输，应提前确认由谁安排以及如何操作。

## 💳 六、德国网购有哪些付款方式？

德国网购常见付款方式包括银行卡、PayPal、银行转账、发票付款以及部分平台提供的分期付款服务。

不同商家支持的付款方式可能不同。

### 1. Kreditkarte：信用卡

部分平台接受 Visa、Mastercard 等信用卡。

付款前应确认：

- 卡片是否支持线上支付。
- 是否需要银行 App 确认。
- 是否需要进行额外身份验证。
- 交易币种及可能的费用。

### 2. Debitkarte：借记卡

部分网店接受借记卡，但是否支持取决于商家、银行卡组织和发卡银行。

不能认为在德国实体店可以刷的银行卡，就一定能在所有网站付款。

### 3. PayPal

PayPal 是德国常见的线上支付方式之一。

使用前应确认：

- 收款方是否正确。
- 交易是否属于符合条件的买家保护范围。
- 商品是否从正确的网站或商家购买。
- 付款是否为正常的商品交易。

买家保护有适用条件，并不意味着任何纠纷都能获得退款。

### 4. Kauf auf Rechnung：发票付款

部分商家允许先收到商品，再按照发票规定付款。

优点是可以先确认订单或收到商品后再支付，但必须注意付款期限。

如果使用第三方付款服务，应查看合同关系、账单发送方、付款账户和逾期费用。

### 5. Lastschrift：直接扣款

部分商家支持通过银行账户直接扣款。

授权前应确认扣款金额、扣款方和相关条件，并保留订单及付款记录。

### 6. Ratenzahlung：分期付款

部分平台或金融服务商提供分期付款。

签约前应检查：

- 实际年利率。
- 总还款金额。
- 手续费。
- 逾期费用。
- 是否涉及额外信贷合同。

不要只看每月还款金额。

### 7. Vorkasse：预付款

部分商家要求先转账，再发货。

对于不熟悉的商家或私人卖家，预付款可能带来较高风险。

如果网站可疑、卖家信息不清楚，或对方要求使用难以追回的付款方式，应谨慎交易。

## 📦 七、德国网购配送方式

德国网购常见配送方式包括送货上门、包裹站自提、包裹店自提及部分商家的指定时间配送。

常见物流公司包括：

- DHL。
- Hermes。
- DPD。
- GLS。
- UPS。

不同商家和配送服务支持的方式并不完全相同。

### 常见德语词汇

| 德语 | 中文 |
|---|---|
| Lieferung | 配送 |
| Versand | 发货、寄送 |
| Versandkosten | 运费 |
| Lieferzeit | 配送时间 |
| Sendungsverfolgung | 物流追踪 |
| Zugestellt | 已显示送达 |
| Zustellversuch | 投递尝试 |
| Abholstation | 自提站 |
| Paketshop | 包裹自提店 |
| Packstation | 包裹柜 |
| Benachrichtigung | 通知 |
| Lieferadresse | 配送地址 |
| Rechnungsadresse | 账单地址 |

### 1. 送货上门

下单时应确认姓名、街道、门牌号、邮政编码和城市是否正确。

如果门铃或信箱上的名字与收件人信息不一致，可能影响投递。

对于合租公寓，应注意楼层、房号及门铃标识。

### 2. Packstation 包裹柜

Packstation 是德国常见的包裹自提设施之一。

部分包裹可以送到 Packstation，之后由收件人自行领取。

使用前应确认：

- 是否需要注册相关服务。
- 订单是否支持该配送方式。
- 地址格式是否符合要求。
- 是否需要 App、取件码或其他验证方式。
- 包裹是否符合尺寸及服务限制。

并非所有商家和所有包裹都支持 Packstation。

### 3. Paketshop 包裹自提店

部分配送服务会把包裹送到合作自提店。

收件人通常需要按照通知中的说明，在规定期限内领取包裹。

领取前应查看：

- 自提地址。
- 营业时间。
- 领取期限。
- 是否需要身份证件或取件码。

## 🏠 八、德国网购地址怎么填写？

填写德国地址时，通常需要提供以下信息：

| 字段 | 含义 | 示例 |
|---|---|---|
| Vorname | 名 | Yu |
| Nachname | 姓 | Ji |
| Straße | 街道 | Musterstraße |
| Hausnummer | 门牌号 | 12 |
| Adresszusatz | 地址补充信息 | Wohnung 3 |
| PLZ | 邮政编码 | 80333 |
| Ort | 城市 | München |
| Land | 国家 | Deutschland |

以上为格式示例，不对应真实收货地址。

### 地址填写建议

1. 姓名应与收件信息保持一致。
2. 街道名称和门牌号不要填反。
3. 确认邮政编码与城市匹配。
4. 合租公寓可以在允许的地址补充栏填写房间信息。
5. 确保门铃或信箱上能识别收件人。
6. 如果需要送到 Packstation，应使用配送服务规定的专用地址格式。

### Lieferadresse 和 Rechnungsadresse 的区别

- Lieferadresse：收货地址。
- Rechnungsadresse：账单地址。

两者可以相同，也可以不同，具体取决于商家要求。

如果你把商品寄到朋友家，但账单使用自己的地址，应分别填写，避免影响配送。

## 🔄 九、德国网购可以在14天内退货吗？

对于符合条件的远程销售合同，消费者通常享有14天的法定撤销权（Widerrufsrecht）。

但**并不是所有网购商品、所有交易和所有卖家都适用完全相同的规则**。

是否适用、期限如何计算，以及撤销后如何返还商品，应根据交易类型和法律规定判断。

### 1. Widerrufsrecht 是什么？

Widerrufsrecht 指符合条件的消费者远程交易撤销权。

在适用该权利的情况下，消费者可以在法定期限内通知商家撤销合同，通常不需要说明理由。

常见的远程销售场景包括消费者通过商家网站订购商品。

### 2. 14天从什么时候开始计算？

对于许多商品销售合同，期限通常从消费者或其指定的第三方实际收到商品之日起计算，而不是一律从下单日或付款日开始计算。

但具体起算方式可能因合同类型而不同。

如果订单分批交付、包含多件商品或属于持续交付合同，期限计算可能存在特殊规则。

### 3. 撤销合同后需要做什么？

通常需要：

1. 在适用期限内向商家明确表达撤销合同的意思。
2. 按照商家的说明或适用法律要求退回商品。
3. 保存撤销通知和相关凭证。
4. 保存退货物流记录。
5. 按照相关规则处理退款。

**仅仅把商品寄回去，不一定能在所有情况下清楚证明你已经有效行使撤销权。**

建议通过可保存记录的方式通知商家，并保留发送凭证。

### 4. 退货运费谁承担？

这取决于商家的事先告知、交易条件及适用法律。

在一些符合条件的撤销交易中，消费者可能需要承担直接退货费用，前提是商家依法履行了相应告知义务。

如果商家承诺免费退货，则应查看其具体承诺和条件。

### 5. 哪些商品可能不适用普通的撤销权？

法律规定了若干例外，具体要看商品类型和交易情况。

例如，部分定制商品、某些易迅速变质的商品，以及符合特定条件的已拆封密封商品，可能不适用通常的撤销权规则。

但不能简单认为所有拆封商品都不能退货。

### 6. 实体店购买和网购不同吗？

不同。

在德国，实体店购买的商品如果没有质量问题，商家通常没有必须接受退货的普遍法定义务。

是否允许退货或换货，通常取决于商家的自愿政策。

## 🛠️ 十、商品有质量问题怎么办？

商品有质量问题时，可能涉及法定瑕疵责任（Gewährleistung）。

这与商家或制造商自愿提供的商业保证（Garantie）不同。

### 1. Gewährleistung 是什么？

Gewährleistung 指法律规定的卖方对商品瑕疵承担的责任。

如果商品不符合合同约定，消费者可能根据具体情况要求修理、更换或进一步法律救济。

具体权利取决于商品情况、交易类型及适用法律。

### 2. Garantie 是什么？

Garantie 通常指商家、制造商或其他保证人自愿提供的额外保证。

其范围、期限和条件取决于保证条款。

商业保证不能简单替代或排除消费者依法享有的强制性权利。

### 3. 遇到质量问题应该怎么做？

建议：

1. 拍摄商品问题的照片或视频。
2. 保存订单确认和付款记录。
3. 联系实际卖家，而不只是物流公司。
4. 清楚说明问题及希望采取的解决方式。
5. 保存所有沟通记录。
6. 如果商家拒绝处理，查询消费者组织提供的建议。

不要因为商品仍在商业保证期内，就忽略可能适用的法定瑕疵责任。

## 🚚 十一、包裹显示已送达，但我没有收到怎么办？

物流显示 Zugestellt（已送达），并不一定意味着你本人已经实际收到包裹。

应先核实具体交付情况。

### 处理步骤

**第一步：检查配送信息**

查看物流页面是否说明包裹被放在指定地点、交给邻居或送到自提点。

**第二步：检查周边位置**

查看门口、信箱附近、包裹柜和邻居处是否有包裹或通知。

**第三步：联系卖家**

如果没有找到包裹，向卖家说明情况，并提供订单号和物流信息。

**第四步：联系配送服务商**

根据卖家或配送商的流程查询包裹状态。

**第五步：保存证据**

保存物流截图、订单确认、商家回复和相关通知。

### 如果包裹被盗怎么办？

如果有证据表明包裹被盗，可以考虑向警方报案。

但是否涉及卖方的交付责任，需要根据具体交易、交付方式和适用法律判断。

不要仅凭物流状态就认定消费者必然承担全部损失。

## ⚠️ 十二、德国网购防诈骗指南

网购诈骗可能发生在假冒网站、第三方卖家、社交媒体广告和私人交易中。

### 常见风险信号

- 商品价格明显低于正常市场水平。
- 网站没有清晰的商家身份和联系方式。
- 卖家只接受难以追回的付款方式。
- 对方催促你立即付款。
- 要求通过陌生链接登录银行账户。
- 要求提供银行卡 PIN、网银密码或短信验证码。
- 收到要求支付额外费用的可疑物流短信。
- 对方要求离开平台，转到不受保护的渠道交易。
- 商品照片、描述和卖家信息相互矛盾。

单独出现某个信号不一定能证明诈骗，但多个信号同时出现时，应特别谨慎。

### 如何检查德国网店？

建议检查：

1. 网站域名是否正确。
2. 商家身份信息是否完整。
3. 联系方式是否可信。
4. 付款方式是否合理。
5. 退货政策和隐私说明是否清晰。
6. 商品价格是否明显异常。
7. 是否存在大量可疑评价或复制内容。

德国商业网站常见的 Impressum 页面通常包含商家身份和联系信息。

但存在 Impressum 不代表网站一定可信，信息仍需核实。

### 收到 DHL、DPD 等物流短信怎么办？

不要直接点击可疑短信中的链接。

可以自行打开官方物流网站或 App，手动输入运单号查询。

如果短信要求输入银行卡信息、网银密码或支付与订单无关的费用，应保持警惕。

### 如果已经付款并怀疑被骗

1. 尽快联系银行或支付服务商。
2. 说明交易情况并询问是否能够停止、撤回或争议处理。
3. 保存付款记录、聊天记录和网站信息。
4. 必要时向警方报案。
5. 如果提供过密码，应尽快更改相关账户密码。
6. 如果泄露了银行卡或网银信息，应立即联系银行采取保护措施。

是否能够追回款项取决于付款方式、交易状态和具体情况，不能保证一定成功。

## ❓ 十四、常见问题 FAQ

### Q1：德国网购一定比实体店便宜吗？

不一定。应比较商品价格、运费、配送时间、退货成本和售后服务。

### Q2：Amazon 上的商品都是 Amazon 自营吗？

不是。平台上可能有 Amazon 自营商品，也可能有第三方卖家销售的商品。购买前应查看实际卖家。

### Q3：德国网购都能在14天内无理由退货吗？

不是。符合条件的远程销售合同通常适用法定撤销权，但法律规定了例外，具体还需结合交易类型和商品情况判断。

### Q4：商品已经拆封，还能退吗？

不能一概而论。是否适用撤销权以及拆封后的处理方式，取决于商品类型、法律规定和具体情况。

### Q5：卖家不退款怎么办？

保存订单、付款、退货和沟通记录，先通过书面方式联系卖家。如果无法解决，可以向相关消费者组织寻求建议，并根据付款方式咨询银行或支付服务商。

### Q6：包裹显示已送达但没有收到，谁负责？

需要核实交付方式、实际交付情况及适用法律。建议先联系卖家并保存物流证据，不要直接认定自己必须承担损失。

### Q7：网购可以用中国银行卡吗？

取决于网站支持的银行卡组织、发卡银行及交易验证要求。建议在付款前检查支持的支付方式，并准备备用方式。

### Q8：德国网购一定需要注册账户吗？

不一定。有些商家支持访客结账（Gastbestellung），有些则要求注册账户。具体以商家规定为准。

### Q9：Packstation 可以接收所有包裹吗？

不可以。是否支持取决于配送服务、商家、包裹尺寸和其他服务条件。

### Q10：网上买到假货怎么办？

保存商品页面、订单、付款记录、包装和商品照片，联系实际卖家并说明情况。必要时向支付服务商或消费者组织咨询后续处理方式。
