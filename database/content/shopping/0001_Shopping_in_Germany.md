# 🛍️ 0001｜德国购物指南 Shopping in Germany

> 在德国生活，去哪里买日用品、食品、衣服、电子产品？dm 和 Rossmann 有什么区别？德国网购有哪些常用平台？打折季什么时候开始？买到不合适的商品能不能退货？
>
> 本指南帮助你快速了解德国的购物渠道、常见商店、支付方式、退货规则和省钱技巧，适合刚到德国的留学生、新居民及长期生活者。

## 🗺️ 一、德国购物渠道总览

德国的购物渠道主要分为线下实体店、网上购物和二手交易三类。

| 购物需求 | 推荐渠道 | 常见选择 |
|---|---|---|
| 日常食品 | 超市、折扣超市 | REWE、EDEKA、Lidl、ALDI、Penny、Netto |
| 洗护用品、清洁用品 | 日化店（Drogerie） | dm、Rossmann、Müller |
| 衣服、鞋子 | 服装店、品牌官网、网购平台 | C&A、H&M、Zalando |
| 电子产品 | 电子产品专卖店、品牌官网 | MediaMarkt、Saturn、Apple |
| 家具、家居用品 | 家居卖场、家具店、网购平台 | IKEA、JYSK、OTTO |
| 药品 | 药房（Apotheke） | 实体药房、合法网上药房 |
| 书籍、文具 | 书店、文具店、网购平台 | Thalia、Müller、Amazon.de |
| 二手商品 | 二手交易平台、跳蚤市场 | Kleinanzeigen、Vinted |
| 生活杂货 | 百货店、折扣店 | Action、TEDi、Woolworth |

以上为常见购物渠道，并不代表所有门店都提供相同商品或价格。

## 🏪 二、德国常见超市怎么选？

德国超市可以大致分为综合超市和折扣超市。

### 1. 综合超市

常见品牌：

- REWE
- EDEKA
- Kaufland

特点：

- 商品种类通常比较丰富。
- 经常可以找到不同品牌的同类商品。
- 部分门店提供熟食、肉类柜台或更多特色商品。
- 价格和商品选择因门店而异。

### 2. 折扣超市

常见品牌：

- Lidl
- ALDI
- Penny
- Netto

特点：

- 自有品牌商品较多。
- 日常食品和基础生活用品通常有较多经济型选择。
- 经常推出每周特价商品。
- 不同门店的商品种类和促销安排可能不同。

### 3. 购物建议

如果你想控制生活成本，可以比较不同超市的自有品牌和每周促销商品。

不必认为综合超市一定更贵，也不必认为折扣超市所有商品都最便宜。对于经常购买的食品，比较单价通常比只看包装价格更有用。

## 🧴 三、dm、Rossmann 和 Müller 有什么区别？

德国的 Drogerie 主要销售日化用品、洗护用品、清洁用品、部分食品、婴儿用品及其他生活杂货。

常见品牌：

- dm
- Rossmann
- Müller

### 常见商品

- 洗发水、护发素
- 沐浴露、洗面奶
- 牙膏、牙刷
- 洗衣液、清洁剂
- 卫生纸、纸巾
- 化妆品、护肤品
- 婴儿用品
- 部分维生素及营养补充剂
- 部分零食、饮料和基础食品

### 购物技巧

1. 比较自有品牌与知名品牌的单价。
2. 查看促销活动和会员优惠。
3. 注意商品容量，不要只比较包装价格。
4. 购买护肤品时检查适用肤质和成分。
5. 购买特殊用途产品时，确认商品用途和使用说明。

注意：Drogerie 并不等于药房（Apotheke）。处方药及许多药品应通过药房购买。

## 🛒 四、德国常用网购平台

德国常见的网上购物渠道包括综合电商、品牌官网和垂直购物平台。

| 平台 | 常见用途 | 购物前注意事项 |
|---|---|---|
| Amazon.de | 日用品、电子产品、家居用品等 | 核实实际卖家、配送和退货条件 |
| Zalando | 服装、鞋类及配饰 | 查看尺码、退货条件及商品说明 |
| OTTO | 家居、家具、服装及其他商品 | 查看配送费用、安装及退货条件 |
| IKEA | 家具、家居用品 | 核实配送范围、运费和组装要求 |
| MediaMarkt | 电子产品、家用电器 | 比较型号、保修及退货条件 |
| 品牌官方网站 | 品牌商品 | 核实网站真实性及销售条款 |
| Kleinanzeigen | 本地二手交易 | 谨慎付款，核实卖家和商品 |

**重要提醒：网购平台不一定是实际卖家。**

同一个平台上的商品可能由平台自营、第三方商家或私人卖家提供。卖家身份不同，交易规则和售后处理方式也可能不同。

### 网购前检查

- 商品是否符合你的需求。
- 卖家是否可信。
- 总价是否包含配送费用。
- 预计送达时间。
- 是否有明确的退货政策。
- 商品是否为新品、翻新商品或二手商品。
- 是否需要自行承担退货运费。

## 💳 五、德国购物如何付款？

德国常见的付款方式包括银行卡、现金、手机支付和部分线上支付服务。

### 1. Girocard 与银行卡

德国商店常见的付款方式包括 Girocard、借记卡及部分信用卡。

需要注意，不是每家商店都接受所有银行卡组织或支付方式。

付款前可以查看收银台、店门口或刷卡终端上的支付标志。

### 2. 现金 Bargeld

德国仍有不少商店接受现金付款。

如果你经常去小型商店、市场或部分餐饮场所，可以适当准备少量现金。

但不能因此认为所有德国商店都只接受现金。许多商店也支持银行卡或手机支付。

### 3. Apple Pay 和 Google Pay

部分商店支持 Apple Pay、Google Pay 等手机支付方式。

能否使用取决于：

- 商店的支付终端。
- 绑定银行卡的支持情况。
- 银行及支付服务的相关限制。

出门前可以检查手机钱包中的银行卡是否已经完成设置。

### 4. PayPal 等线上支付方式

部分网购平台支持 PayPal 或其他线上支付方式。

付款前应确认：

- 收款方是否可信。
- 商品是否确实来自目标商家。
- 付款方式是否提供适用的买家保护。
- 相关保护是否适用于本次交易。

不要认为任何支付方式都能保证追回所有损失。

## 🏷️ 六、德国什么时候买东西比较便宜？

德国商店全年都会有促销，但具体折扣时间取决于品牌、商品和商家安排。

### 常见促销时机

| 时间或活动 | 常见情况 |
|---|---|
| 年初促销 | 部分服装、家居及季节性商品降价 |
| 换季期间 | 部分季节性服装和用品促销 |
| Black Friday | 许多零售商推出促销，但折扣幅度不一 |
| Cyber Monday | 部分线上商家推出促销 |
| 圣诞节前后 | 礼品、装饰及部分季节性商品促销 |
| 超市每周促销 | 食品及部分日用品可能降价 |
| 品牌会员活动 | 部分商品可获得额外优惠 |

### 如何判断折扣是否划算？

不要只看原价和折扣百分比。

建议比较：

1. 当前售价。
2. 其他商家的售价。
3. 商品的规格和型号。
4. 配送费用。
5. 退货条件。
6. 自己是否真的需要这件商品。

有些商品在促销期间并不一定比其他商家的日常售价更低。

## 🧾 七、德国购物小票要不要保留？

建议保留重要购物凭证，尤其是购买价格较高的商品时。

德语常见表达：

- Kassenbon：收银小票
- Rechnung：发票
- Bestellbestätigung：订单确认
- Versandbestätigung：发货确认
- Rücksendebeleg：退货凭证
- Gewährleistung：法定瑕疵责任
- Garantie：商业保证

### 哪些情况尤其应该保留？

- 电子产品。
- 家用电器。
- 家具。
- 价格较高的商品。
- 需要报销的商品。
- 可能需要退货或提出质量问题的商品。

网购时，应保存订单确认、付款记录、商品页面和相关通信。

**注意：小票丢失不一定意味着你自动失去所有法定权利。** 但你可能需要通过其他证据证明购买事实、购买时间或交易内容。

## 🔄 八、德国买东西可以退货吗？

这取决于购买方式、商品情况及商家的退货政策。

### 1. 实体店购物

如果商品没有质量问题，只是因为改变主意、不喜欢颜色或买错尺码，德国法律通常不要求实体店一律接受退货。

是否可以退货或换货，通常要看商家自己的政策。

因此，购买前应询问：

- 是否允许退货。
- 退货期限有多长。
- 是否需要原包装。
- 是否必须提供小票。
- 是否可以退款，还是只能换货或获得购物券。

### 2. 网购

消费者通过符合条件的远程销售合同购买商品时，通常享有14天的法定撤销权（Widerrufsrecht）。

但存在法律规定的例外，具体适用范围取决于交易类型及商品情况。

此外，撤销权的起算时间、通知方式、退货费用及其他要求也应根据具体交易判断。

### 3. 商品有质量问题

如果商品存在不符合合同约定的情况，可能涉及法定瑕疵责任（Gewährleistung）。

这与商家自愿提供的商业保证（Garantie）不是同一个概念。

消费者在相关法律规定的条件下，可能享有要求修理、更换或进一步救济的权利。

## 🚚 九、德国网购配送需要注意什么？

德国网购可能涉及普通包裹、快递、包裹站自提或送货上门等方式。

常见配送服务商包括 DHL、Hermes、DPD、GLS 和 UPS 等。

下单时应检查：

- 收货地址是否正确。
- 姓名是否与门铃或信箱标识一致。
- 是否可以使用 Packstation 或 Paketshop。
- 是否需要签收。
- 预计送达日期。
- 包裹未能投递时的处理方式。

### 包裹没有收到怎么办？

1. 检查订单页面和物流追踪信息。
2. 查看是否被放在指定地点或交给邻居。
3. 核实包裹站或自提点信息。
4. 联系卖家或相关配送服务商。
5. 保存订单、物流记录和沟通凭证。

如果物流显示已经送达，但你实际上没有收到包裹，不要直接假设自己必须承担全部损失。应先核实交付情况，并根据交易类型及适用法律处理。

## ♻️ 十、德国二手购物

在德国购买二手商品，可以考虑二手平台、实体二手商店和跳蚤市场。

常见渠道包括：

- Kleinanzeigen：本地二手交易。
- Vinted：服装及配饰交易。
- 跳蚤市场（Flohmarkt）。
- 二手家具店。
- 部分专业翻新电子产品商家。

### 二手购物的优势

- 价格可能低于新品。
- 可以找到停产或较难购买的商品。
- 有助于重复利用物品。
- 适合购买家具、家电、服装和生活用品。

### 二手购物的风险

- 商品可能存在未披露的损坏。
- 私人交易的消费者保护规则可能与商家销售不同。
- 部分商品没有原始发票。
- 线上交易可能遇到诈骗。
- 电子产品可能存在电池老化或隐藏故障。

### 交易建议

1. 尽量查看商品实物。
2. 对电子产品检查基本功能。
3. 询问是否有原始购买凭证。
4. 确认商品状态、价格和交付方式。
5. 谨慎处理要求提前转账或站外付款的交易。
6. 不要向陌生人提供银行登录信息、验证码或身份证件的非必要信息。

## ⚠️ 十一、德国购物常见注意事项

### 1. 德国商店营业时间

德国商店的营业时间因州、城市、商家及星期而异。

许多普通零售店在星期日不营业，但火车站、机场及法律允许的特定商店可能例外。

出门前应检查具体门店的营业时间，尤其是星期日及公共假期。

### 2. 商品价格与押金

部分饮料包装需要支付押金（Pfand）。

购物时应区分商品本身的价格与包装押金。符合条件的包装退回指定回收渠道后，通常可以退还相应押金。

并非所有包装都适用相同的押金规则。

### 3. 购物袋

德国不少商店不免费提供购物袋。

建议自带购物袋，既方便，也可以减少额外支出。

### 4. 电子产品的插头和规格

购买电子产品时，应确认：

- 是否适用于德国电源标准。
- 插头类型是否合适。
- 商品是否适用于欧洲市场。
- 保修和售后服务适用地区。
- 商品是否支持所需语言及功能。

### 5. 线上商家真实性

购物前检查网站地址、卖家信息、付款方式、退货政策和联系方式。

价格明显低于正常市场水平、要求使用不可逆付款方式或催促站外交易，都可能是风险信号。

## 💡 十二、德国购物省钱技巧

### 1. 优先比较单价

对于食品、洗衣液和清洁用品，可以比较每公斤、每升或每件的价格。

德国商品标签上常见的基本计价单位包括：

- Grundpreis：基本单价
- Preis pro Kilogramm：每公斤价格
- Preis pro Liter：每升价格

### 2. 关注自有品牌

超市及日化店的自有品牌可能提供更经济的选择。

但不同品牌的配方、质量和适用场景可能不同，应根据实际需求选择。

### 3. 使用官方优惠活动

可以关注商家的官方应用、会员计划和每周促销信息。

使用优惠券前，应检查有效期、适用商品和最低消费条件。

### 4. 比较网购总价

不要只比较商品售价。

最终成本还可能包括：

- 配送费。
- 安装费。
- 退货费用。
- 会员费用。
- 特殊配送服务费用。

### 5. 二手商品优先检查状态

对于家具、电器和电子产品，低价不一定意味着更划算。

应将商品状态、剩余使用寿命、运输成本和可能的维修费用一起考虑。

## ❓ 十三、常见问题 FAQ

### Q1：德国哪里买日用品最便宜？

没有适用于所有商品的统一答案。可以比较 Lidl、ALDI、Penny、Netto、dm 和 Rossmann 等商家的自有品牌及促销价格。

### Q2：dm 和 Rossmann 哪个更便宜？

取决于具体商品和促销活动。建议比较同规格商品的单价，而不是只比较品牌。

### Q3：德国实体店买的衣服可以退吗？

如果商品没有质量问题，实体店通常没有必须接受退货的普遍法定义务。是否接受退货或换货，要看商家的政策。

### Q4：德国网购都可以在14天内无理由退货吗？

并非所有交易都适用14天撤销权。需要符合相关法律条件，并注意法定例外及具体起算规则。

### Q5：商品有质量问题，商家不让退货怎么办？

应先确认问题是否属于法定瑕疵责任范围，再根据情况要求适当的法律救济。商家自愿提供的商业保证与法定瑕疵责任不同。

### Q6：德国星期日可以买东西吗？

部分商店可能营业，但许多普通零售店星期日关闭。应提前查询具体门店。

### Q7：德国购物必须使用现金吗？

不需要。许多商店接受银行卡或手机支付，但具体支付方式取决于商家。

### Q8：德国买东西的小票需要保存多久？

没有适用于所有购物场景的统一保存期限。对于高价商品、电子产品及可能涉及退货或质量争议的商品，建议保存购买凭证和相关记录。

### Q9：Kleinanzeigen 上买东西安全吗？

可以进行正常的二手交易，但需要谨慎核实卖家、商品和付款方式。尽量当面检查商品，并避免可疑的提前转账要求。

### Q10：德国商品打折时一定最便宜吗？

不一定。建议比较其他商家的售价、商品规格、配送费用和历史价格信息，判断实际优惠程度。
