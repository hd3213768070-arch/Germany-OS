# 📦 0005｜德国搬家全流程指南 Moving House

在德国搬家，不只是把家具从旧住所搬到新住所。你还需要处理租房合同、退租通知、押金、房屋交接、住址登记，以及银行、保险和其他机构的地址更新。

如果没有提前规划，可能会遇到退租期限已过、押金迟迟无法退还、搬家当天拿不到钥匙，或者重要信件寄到旧地址等问题。

本指南按照搬家前、搬家当天和搬家后的顺序，整理整个搬家过程中的主要事项，帮助你减少遗漏。

**适用人群：** 在德国更换公寓、搬到其他城市、学生宿舍搬迁，以及准备离开当前住所的人。

> 注意：租赁合同、退租期限、押金和房屋交接要求可能因合同及具体情况而不同。涉及法律期限时，应以适用法律、租赁合同和专业意见为准。

## 📋 一、德国搬家的完整流程

| 阶段 | 主要任务 | 需要注意的事项 |
|---|---|---|
| 搬家前数周至数月 | 确认新住所、检查旧合同、安排退租 | Kündigungsfrist、租金、押金 |
| 搬家前数周 | 预约搬家公司或安排车辆 | 搬运费用、停车、家具尺寸 |
| 搬家前一至两周 | 整理物品、通知相关机构 | 网络、电费、地址变更 |
| 搬家前几天 | 打包、确认钥匙交接时间 | 贵重物品、重要文件、清洁 |
| 搬家当天 | 检查房屋、搬运物品、记录房屋状况 | Übergabeprotokoll、钥匙数量 |
| 搬家后 | 办理住址登记、更新地址 | Anmeldung 或 Ummeldung |
| 搬家后数周 | 检查押金、账单和合同状态 | 旧住所费用、最终账单 |

具体时间应根据新旧租约的日期、当地预约情况和个人需求调整。

## 🏠 二、第一步：确认新住所

搬家计划应从确认新住所开始。

在正式确定搬家日期之前，建议确认以下事项。

### 1. 检查新租房合同

重点确认：

- 租赁合同的开始日期。
- 房屋是否可以按计划入住。
- 房租和押金的金额及付款方式。
- 是否包含暖租 Nebenkosten。
- 是否需要单独办理电费、网络或其他服务。
- 是否有家具，以及哪些物品需要自行购买。
- 钥匙领取时间和交接方式。

如果新合同的开始日期早于旧合同的结束日期，可能需要同时承担两套房屋的费用。

建议提前计算这段时间的房租、押金和搬家费用，避免资金安排出现问题。

### 2. 确认入住条件

搬家前应与房东或物业确认：

- 是否已经完成必要的入住手续。
- 钥匙在哪里领取。
- 是否可以提前搬入家具。
- 是否存在搬运时间限制。
- 搬家车辆能否临时停靠。
- 是否需要提前保护电梯、楼梯或公共区域。

如果公寓位于高层、老式建筑或没有电梯的楼房，还应提前评估大型家具的搬运难度。

### 3. 确认 Wohnungsgeberbestätigung

如果搬入新住所后需要办理 Anmeldung，应提前询问房东或住房提供者能否提供 Wohnungsgeberbestätigung（住房提供者证明）。

该证明通常用于住址登记，不能简单地用租赁合同或付款凭证替代。

## 📄 三、第二步：处理旧住所的退租

搬家过程中最容易产生额外费用的环节之一，就是没有正确处理旧租赁合同。

### 1. 检查 Kündigungsfrist

Kündigungsfrist 是解约通知期限。

在德国，住宅租赁的普通退租通常需要遵守法定或合同适用的通知规则。对于一般的无固定期限住宅租赁合同，租客通常需要提前三个月通知退租，但具体情况仍应结合合同、租赁关系和适用法律判断。

应特别注意：

- 退租通知是否必须采用书面形式。
- 通知需要在什么时候送达房东。
- 退租日期如何确定。
- 是否存在固定期限合同或特殊约定。
- 房东是否已经确认收到通知。

**仅仅告诉房东自己准备搬走，并不一定构成有效的退租通知。**

如果不确定通知期限，应尽早检查合同，并在必要时寻求专业建议。

### 2. 提前规划退租日期

建议将以下日期记录在同一份日历中：

- 新租赁合同开始日期。
- 旧租赁合同结束日期。
- 搬家公司的预约日期。
- 旧住所交钥匙的日期。
- 新住所领取钥匙的日期。
- 旧住所最终检查和交接的日期。

如果旧住所尚未正式结束租赁关系，即使已经搬走，也可能仍需要支付租金。

### 3. 不要忽略旧住所的附加费用

除了基本房租，还应确认：

- Nebenkosten（附加费用）的最终结算。
- 电费是否需要抄表和结算。
- 网络或其他服务是否需要取消或迁移。
- 是否有尚未支付的账单。
- 是否需要提供新的通信地址。

如果费用通过自动扣款支付，应在确认合同终止和最终账单处理方式后，再决定是否调整付款安排。

## 💶 四、第三步：准备搬家预算

搬家费用不仅包括搬运费，还可能涉及新旧住所的重叠租金和其他支出。

| 费用项目 | 可能产生的费用 |
|---|---|
| 新住所押金 Kaution | 根据新租赁合同支付 |
| 新旧住所重叠租金 | 两份租约时间重叠时产生 |
| 搬家公司 | 根据距离、物品数量和服务内容收费 |
| 租车 | 自行搬家时可能需要 |
| 包装材料 | 纸箱、胶带、防护材料 |
| 家具和家电 | 新住所缺少必要物品时 |
| 清洁用品 | 搬家前后清洁 |
| 电费和网络 | 新旧住所的合同调整及可能的重叠费用 |
| 临时住宿 | 新旧住所无法衔接时可能需要 |

建议提前制定预算，并留出一定的备用资金。

特别是在慕尼黑等住房成本较高的城市，新旧租约重叠可能带来较大的短期支出。

## 🚚 五、第四步：选择搬家方式

搬家方式主要取决于物品数量、距离、预算和个人时间。

### 1. 自己搬家

如果物品较少，可以考虑自行搬运。

需要提前准备：

- 适合的车辆。
- 纸箱和包装材料。
- 搬运人员。
- 停车及装卸安排。
- 大型家具的拆装工具。
- 运输过程中保护家具和物品的材料。

如果使用租赁车辆，应确认驾驶资格、车辆尺寸、保险范围、押金及还车要求。

### 2. 租用搬家车辆

如果家具较多，但不需要完整的搬家服务，可以考虑租用厢式车或其他适合搬运的车辆。

预订前应确认：

- 车辆尺寸是否适合家具。
- 驾照是否符合租车条件。
- 费用是否包含里程。
- 是否需要支付押金。
- 车辆保险及免赔额。
- 取车和还车时间。
- 是否允许跨城市或跨境行驶。

### 3. 委托搬家公司

如果物品较多、距离较远，或者需要搬运大型家具，可以考虑搬家公司。

询价时建议说明：

- 旧住所和新住所的位置。
- 两边是否有电梯。
- 楼层和搬运距离。
- 家具和纸箱的数量。
- 是否需要拆装家具。
- 是否需要打包和清洁服务。
- 搬家日期及时间要求。

比较报价时，不要只看总价，还应确认服务范围、额外收费和损坏赔偿规则。

## 📦 六、第五步：打包与搬家前准备

建议提前整理物品，不要等到搬家前一天才开始打包。

### 1. 分类整理

可以将物品分为：

- 必须随身携带的文件。
- 日常用品。
- 厨房用品。
- 衣物和床品。
- 家具及电器。
- 需要出售、捐赠或丢弃的物品。

搬家是整理物品的好机会。对于不再需要的东西，可以提前处理，减少搬运量。

### 2. 标记纸箱

建议在纸箱外标记：

- 主要物品类别。
- 新住所对应的房间。
- 是否易碎。
- 是否需要优先拆箱。

例如，厨房用品、书籍和床品可以分别打包，避免搬到新住所后难以寻找。

### 3. 单独保存重要文件

以下物品建议随身携带，而不是放在普通搬家纸箱里：

- 护照及居留文件。
- 租赁合同。
- 银行卡和重要金融文件。
- 医疗保险资料。
- 学校或工作单位的重要文件。
- 搬家当天需要使用的钥匙。
- 重要电子设备及其必要配件。

### 4. 提前处理冰箱和大型电器

搬家前应根据设备说明处理冰箱、洗衣机等电器。

如果需要断电、排水或拆卸，应预留足够时间，并妥善固定可移动部件。

不要在没有做好保护措施的情况下直接运输大型电器。

## 🔑 七、第六步：搬家当天的房屋交接

搬家当天应分别检查旧住所和新住所，尽可能保留清晰的书面记录。

### 1. 旧住所：检查房屋状况

交房前可以检查：

- 房间、厨房和卫生间。
- 墙壁、地板、门窗。
- 家具和设备。
- 水表、电表或其他适用的计量设备。
- 所有钥匙是否齐全。
- 是否遗留个人物品。
- 是否完成约定的清洁工作。

对于房屋损坏或存在争议的地方，应拍照并记录。

### 2. 填写 Übergabeprotokoll

Übergabeprotokoll 是房屋交接记录。

建议记录：

- 交接日期。
- 房屋状况。
- 已发现的损坏。
- 相关设备的状况。
- 适用的水电读数。
- 交还或接收的钥匙数量。
- 双方需要确认的其他事项。

交接记录应尽量客观、准确。对存在争议的内容，不要在没有理解的情况下随意签字。

双方确认后，应各自保存一份记录。

### 3. 新住所：入住检查

领取新住所钥匙后，建议：

- 检查房屋和设备。
- 拍摄入住时的房屋状况。
- 记录适用的水电读数。
- 确认钥匙数量。
- 检查是否有遗留物品。
- 确认门锁、暖气和基本设施是否正常。

如果发现问题，应尽快向房东或物业报告，并保留书面记录。

## 🏛️ 八、第七步：搬家后办理住址登记

搬入新住所后，需要根据自己的实际情况判断应该办理哪种住址登记手续。

### 1. Anmeldung 或 Ummeldung

如果在德国搬到新的住所，通常需要在新住址办理相应的登记手续。

具体使用的服务名称可能因城市和办理场景而不同。应查询当地 Bürgeramt 或 Bürgerbüro 的要求。

通常需要关注：

- 护照或其他有效身份证件。
- Wohnungsgeberbestätigung。
- 是否需要预约。
- 办理期限。
- 是否可以线上办理。
- 是否需要其他补充材料。

按照德国《联邦登记法》BMG 第17条，一般情况下，搬入住所后应在两周内完成登记。具体适用情况及例外应以法律规定和主管机构的说明为准。

详细指南：[德国住址登记 Anmeldung](../government/0002_Anmeldung.md)。

### 2. 保存登记证明

完成登记后，应保存 Meldebestätigung。

这份证明可能会用于后续行政手续、银行业务或其他需要确认地址的场景。

如果搬家涉及不同城市，或者个人身份发生变化，还应根据实际情况确认是否需要办理其他手续。

## 📮 九、第八步：更新重要机构的地址

搬家后，除了办理住址登记，还应主动检查哪些机构需要更新你的地址。

| 机构或服务 | 需要检查的事项 |
|---|---|
| 银行 | 通信地址、银行卡寄送地址 |
| 医疗保险机构 | 个人地址和通信信息 |
| 雇主 | 工资及人事系统中的地址 |
| 大学 | 学生信息系统中的地址 |
| 手机和网络服务商 | 合同地址、服务地址 |
| 电力供应商 | 新旧住所的合同及计量信息 |
| 租房相关机构 | 旧住所结算及押金通信地址 |
| 其他保险机构 | 保单中的地址信息 |
| 订阅及配送服务 | 账单地址和配送地址 |

不要假定所有机构都会自动获取你的新地址。

对于重要机构，建议登录个人账户确认更新是否成功，并保存相关确认信息。

## ⚡ 十、第九步：处理电费、网络和其他合同

搬家可能影响多个服务合同，应分别确认每项服务的处理方式。

### 1. 电费

如果旧住所的电费由自己与供应商签约，应联系供应商确认搬出手续。

通常需要关注：

- 旧住所的搬出日期。
- 最终电表读数。
- 新住所的入住日期。
- 新旧住所是否需要分别办理合同。
- 最终账单的寄送地址。

如果电费包含在租金或附加费用中，处理方式可能不同，应根据合同确认。

### 2. 网络

搬家前应询问网络服务商：

- 现有合同能否迁移到新地址。
- 新住所是否支持原有服务。
- 是否需要技术人员上门。
- 是否需要更换设备。
- 是否涉及额外费用或合同期限变化。

不要在没有确认新住所网络服务安排的情况下，直接假定原合同可以无缝迁移。

### 3. 手机和其他订阅

检查是否需要更新账单地址、配送地址或联系方式。

如果某项服务不再需要，应根据合同中的取消规则办理，而不是简单地停止付款。

## 💶 十一、第十步：检查押金与最终账单

搬出旧住所后，建议持续跟进押金和相关费用。

### 1. Kaution（租房押金）

押金通常用于保障房东在租赁关系中可能产生的合法请求，例如符合条件的未付费用或损坏赔偿。

退还时间和金额可能取决于房屋状况、未结算费用及具体租赁关系。

搬家时建议：

- 保存押金支付凭证。
- 保存房屋交接记录。
- 保存搬出时的照片。
- 提供有效的通信地址。
- 记录与房东关于押金的沟通。

如果押金迟迟没有退还，应先询问原因，并检查是否存在尚未结算的费用或其他争议。

### 2. Nebenkostenabrechnung（附加费用结算）

搬出后，旧住所可能仍涉及附加费用的最终结算。

应保存租赁期间的相关账单，并确认房东或物业是否会在后续寄送结算结果。

如果收到补缴要求或对结算存在疑问，应检查账单项目、结算期间及相关依据。

## ⚠️ 十二、德国搬家常见错误

### 错误一：没有提前处理退租通知

如果错过适用的解约通知期限，可能需要继续承担租金。

**建议：** 在确定搬家计划后，首先检查旧租赁合同和退租规则。

### 错误二：没有确认新住所的入住日期

如果旧住所已经结束租赁，而新住所尚未能够入住，可能需要临时住宿和额外搬运。

**建议：** 提前确认新旧住所的时间安排，并准备备用方案。

### 错误三：搬家当天没有拍照

缺少入住和搬出时的记录，可能增加后续处理损坏争议的难度。

**建议：** 对房屋状况、设备和适用的计量读数进行记录。

### 错误四：只办理住址登记，没有更新其他机构

部分重要信件可能仍然寄往旧地址。

**建议：** 建立银行、保险、学校、雇主和服务商的地址更新清单。

### 错误五：认为押金会立即退还

押金退还可能需要时间，尤其是在仍有费用需要结算或双方存在争议时。

**建议：** 保存相关凭证，并主动跟进处理进度。

### 错误六：忽略搬家期间的合同重叠费用

新旧租约重叠时，可能同时产生房租、电费或网络费用。

**建议：** 提前计算重叠期间的支出，并确认每份合同的结束日期。
