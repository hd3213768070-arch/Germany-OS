# 💼 0004｜德国工作办事指南 Working in Germany

在德国找工作和正式入职，涉及的不只是简历和劳动合同，还包括工作许可、税务信息、社会保险、工资发放以及劳动权益。

本指南按照求职、入职、工作期间和离职的顺序，整理在德国工作时需要关注的主要事项，帮助你建立完整的办事流程。

**适用人群：** 在德国求职的留学生、兼职人员、Werkstudent、Minijob 从业者、全职员工，以及计划来德国工作的外国人。

> 注意：不同就业形式、居留身份和个人情况适用的规则可能不同。涉及工作许可、税务和社会保险时，应以主管机构的最新规定为准。

## 📋 一、在德国工作的主要阶段

| 阶段 | 主要任务 | 需要关注的事项 |
|---|---|---|
| 求职前 | 明确工作类型和求职方向 | 工作许可、语言要求、资格条件 |
| 求职期间 | 准备简历、申请职位、参加面试 | 申请材料、岗位要求、招聘流程 |
| 签约前 | 阅读劳动合同 | 工资、工时、试用期、休假、解约期限 |
| 入职时 | 提交必要信息并完成登记 | 身份信息、税务信息、保险安排 |
| 工作期间 | 核对工资单、工时和休假记录 | 工资、加班、社保、劳动权益 |
| 离职时 | 按规定完成离职手续 | 解约通知、最后工资、证明文件 |

不同岗位和就业形式的具体流程可能有所不同。

## 🔎 二、第一步：确认自己是否可以工作

在开始求职前，首先要确认自己的身份是否允许从事目标工作。

### 1. 欧盟公民

欧盟公民通常可以根据欧盟自由流动规则在德国工作，但仍需遵守适用的劳动、税务和社会保险规定。

### 2. 非欧盟公民

非欧盟公民需要根据自己的签证或居留许可确认就业权限。

应检查：

- 当前居留身份是否允许工作。
- 是否存在工作时间或工作类型限制。
- 是否需要额外许可。
- 计划从事的工作是否符合居留许可的条件。

如果居留许可对工作存在限制，应先确认允许工作的范围，不要仅凭雇主愿意录用就开始工作。

### 3. 留学生兼职

持有学生居留许可的非欧盟学生，需要遵守适用的学生就业规定。

在接受工作之前，应确认：

- 该工作是否属于允许从事的就业类型。
- 是否需要计算工作日或工作时间限制。
- 是否存在实习、校内工作或其他特殊规则。
- 工作是否会影响自己的居留条件。

学生就业规定可能因身份和工作形式而异，应查询官方信息。

官方入口：[Make it in Germany｜德国官方人才与就业信息门户](https://www.make-it-in-germany.com/)。

## 📝 三、第二步：准备求职材料

德国的求职材料通常需要根据岗位要求进行调整。

### 1. Lebenslauf（简历）

简历通常包括：

- 个人基本信息和联系方式。
- 教育经历。
- 工作和实习经历。
- 专业技能。
- 语言能力。
- 与岗位相关的其他经历。

应保证信息真实、清晰，并突出与岗位有关的经验。

### 2. Anschreiben（求职信）

部分岗位会要求提交求职信。求职信应简洁说明：

- 为什么申请该岗位。
- 自己具备哪些相关能力。
- 过去的经历如何与岗位要求匹配。
- 为什么希望加入该公司。

并非所有岗位都要求求职信，应以招聘广告的要求为准。

### 3. Zeugnisse（证明文件）

根据岗位要求，可能需要准备：

- 学历证书。
- 成绩单。
- 工作证明。
- 实习证明。
- 语言证书。
- 职业资格证明。

部分受监管职业可能对学历认可、资格认证或语言能力有额外要求。

### 4. 面试准备

面试前建议了解：

- 岗位职责和招聘要求。
- 工作地点和工作时间。
- 公司基本情况。
- 薪资范围及合同条件。
- 自己的居留和就业条件。

如果对工资、工作时间或工作内容存在疑问，应在接受职位之前询问清楚。

## 📄 四、第三步：签署劳动合同

收到录用通知后，不要只关注工资数字，还应认真阅读劳动合同。

常见的合同类型包括：

| 德语术语 | 含义 | 需要关注的事项 |
|---|---|---|
| Arbeitsvertrag | 劳动合同 | 双方权利义务、工资和工时 |
| Vollzeit | 全职工作 | 约定工时及适用的劳动规则 |
| Teilzeit | 兼职或非全职工作 | 实际工时及工资计算方式 |
| Minijob | 符合相应法定条件的低收入就业形式 | 收入限额、社保和税务处理 |
| Werkstudent | 符合学生工规则的工作形式 | 学生身份、工作性质和社保规定 |
| Befristeter Vertrag | 固定期限合同 | 合同开始和结束日期 |
| Unbefristeter Vertrag | 无固定期限合同 | 合同终止及解约规则 |
| Probezeit | 试用期 | 试用期长度及适用的解约规定 |

### 签约前重点检查

**工资：**
- 工资是按小时还是按月计算。
- 工资是税前 Brutto 还是税后 Netto。
- 工资发放日期是什么时候。
- 是否存在奖金、补贴或其他额外收入。

**工时：**
- 每周约定工作多少小时。
- 排班方式是什么。
- 是否需要轮班或周末工作。
- 加班如何记录和处理。

**休假：**
- 每年有多少天带薪休假。
- 休假申请和批准流程是什么。
- 休假期间工资如何处理。

**合同期限：**
- 是否有试用期。
- 合同是否有固定期限。
- 解约通知期限是什么。
- 是否存在特殊的工作安排或附加条款。

如果合同内容不明确，应在签署前要求雇主解释，并保存最终签署的合同副本。

## 🪪 五、第四步：准备入职信息

正式入职时，雇主通常需要收集完成工资结算、税务处理和社会保险登记所需的信息。

具体材料取决于工作类型、个人身份和雇主流程。

常见信息包括：

- 身份证件及适用的工作许可。
- 个人联系方式和地址。
- Steuer-ID（个人税务识别号码）。
- 银行账户信息。
- 医疗保险相关信息。
- 社会保险号码（适用时）。
- 其他雇主要求的入职材料。

如果缺少某项材料，应尽早联系雇主确认如何补交。

### Steuer-ID 和 Sozialversicherungsnummer 有什么区别？

这两个号码的用途不同。

| 项目 | 主要用途 |
|---|---|
| Steuer-ID | 个人税务识别，通常用于工资税务处理 |
| Sozialversicherungsnummer | 社会保险相关识别，用于相关保险记录和就业手续 |

不要把它们与银行账号或其他个人编号混淆。

详细信息请阅读：

- [德国 Steuer-ID](../government/0003_Tax_ID.md)
- [德国社会保障体系 Sozialversicherung](../government/0007_Social_Security.md)

## 💶 六、第五步：理解工资单、税务和社会保险

在德国工作期间，应定期检查工资单，而不是只关注银行卡到账金额。

### 1. Brutto 和 Netto

- **Brutto：** 税前工资。
- **Netto：** 扣除适用项目后实际发放的工资。

两者之间的差额可能包括工资税、社会保险缴费及其他适用扣款。

实际扣款取决于个人税务情况、就业类型、保险安排和其他因素。

### 2. 工资单中的常见项目

| 德语术语 | 中文解释 |
|---|---|
| Bruttolohn | 税前工资 |
| Nettolohn | 实际净工资 |
| Lohnsteuer | 工资税 |
| Krankenversicherung | 医疗保险 |
| Pflegeversicherung | 护理保险 |
| Rentenversicherung | 养老保险 |
| Arbeitslosenversicherung | 失业保险 |
| Sozialversicherung | 社会保险 |
| Überstunden | 加班时间 |
| Zuschlag | 补贴或附加报酬 |

并非每种就业形式都会以相同方式缴纳所有保险费用。

### 3. 不同工作形式的区别

**普通雇佣关系：**

通常涉及工资税和适用的社会保险缴费，雇主与雇员按照相关规定承担相应部分。

**Werkstudent：**

符合学生工规则时，社会保险处理可能与普通雇佣关系不同。学生通常仍需要有适用的医疗保险安排。

**Minijob：**

Minijob 适用特定的收入和就业规则，其税务和社会保险处理与普通雇佣关系存在差异。

不要仅凭职位名称判断自己的保险义务，应结合实际工作情况和适用规定确认。

详细指南：

- [德国社会保障体系 Sozialversicherung](../government/0007_Social_Security.md)
- [德国个人报税 Steuererklärung](../government/0004_Tax_Return.md)

## ⏰ 七、第六步：工作期间需要注意什么？

### 1. 记录实际工时

建议定期检查排班和工时记录，特别是在以下情况下：

- 实际工作时间与排班不同。
- 存在加班。
- 请假或休假。
- 临时换班。
- 工资单中的工时与自己的记录不一致。

如果发现差异，应尽早向主管或人事部门询问。

### 2. 理解加班规则

加班的处理方式可能取决于劳动合同、适用的集体协议和相关法律规定。

应确认：

- 哪些时间被记录为加班。
- 加班是否需要事先批准。
- 加班如何补偿。
- 是否可以通过调休处理。
- 工资单或工时账户如何体现加班。

不要仅凭口头约定判断加班一定会以某种方式结算。

### 3. 申请休假

带薪休假通常受到法律规定和劳动合同的约束，但具体休假安排仍需要遵循适用规则。

建议：

- 提前查看剩余休假天数。
- 按照雇主要求提交申请。
- 等待正式批准后再安排不可更改的行程。
- 保存休假申请及批准记录。
- 了解年末剩余休假的处理方式。

### 4. 保存工资和工作记录

建议保存：

- 劳动合同及补充协议。
- 每月工资单。
- 排班和工时记录。
- 休假申请及批准记录。
- 雇主关于工资、工时和合同变更的重要通知。

这些资料有助于核对工资、处理争议以及准备税务申报。

## ⚠️ 八、遇到工作问题时怎么办？

在德国工作期间，可能遇到工资未到账、工时记录不一致、合同条款不明确或休假争议等问题。

建议按照以下顺序处理：

1. **核对文件：** 查看劳动合同、工资单和相关记录。
2. **整理事实：** 记录发生时间、涉及金额和具体情况。
3. **联系雇主：** 通过适当的书面方式说明问题，并保留沟通记录。
4. **确认处理期限：** 检查合同或适用规则中是否存在需要及时主张权利的期限。
5. **寻求帮助：** 如果问题无法解决，可以考虑联系工会、劳动咨询机构或律师。

如果收到雇主或政府机构的正式通知，应认真检查其中的要求和期限。

不要因为问题暂时没有解决，就忽略可能影响自己权利的时限。

## 🚪 九、第七步：离职时需要处理什么？

离职时，除了结束工作关系，还需要确认工资、文件和其他后续事项。

### 1. 确认解约规则

辞职或结束合同前，应检查：

- 合同中的 Kündigungsfrist（解约通知期限）。
- 是否处于试用期。
- 合同是否为固定期限。
- 是否需要书面通知。
- 是否存在特殊的解约规定。

不同合同类型和具体情况适用的规则可能不同。如果对期限有疑问，应先确认，不要仅凭一般经验判断。

### 2. 核对最后一笔工资

离职后应检查：

- 最后一笔工资是否已经支付。
- 剩余工时是否正确记录。
- 未休假期如何处理。
- 是否还有应支付的奖金或补贴。
- 是否收到最终工资单。

如果发现问题，应及时与雇主联系。

### 3. 保存离职文件

根据个人情况，应保存：

- 离职或解约相关文件。
- 最终工资单。
- 工作证明或 Arbeitszeugnis（工作评价证明，适用时）。
- 与社会保险有关的文件。
- 后续求职或税务申报需要的材料。

如果离职后继续领取工资、申请失业相关待遇或开始新工作，还应确认是否需要办理额外手续。
