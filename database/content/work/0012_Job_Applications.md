# 0012 Job Applications

在德国找工作时，Bewerbung 不只是把简历发出去。完整的求职申请通常包括寻找职位、准备材料、提交申请、参加面试以及收到结果几个环节。不同公司和职位的要求会有所不同，但整体流程比较固定。

## 1. 从 Stellenanzeige 开始

找到职位后，先看 Stellenanzeige（招聘信息），重点确认：

- 职位名称和工作内容
- 工作地点以及是否支持远程办公
- Vollzeit、Teilzeit、Werkstudent、Minijob 等工作形式
- 要求的学历、专业和工作经验
- 语言要求
- 技能和软件要求
- Arbeitsbeginn（预计入职时间）
- Gehalt，如果招聘信息中有注明
- Bewerbungsschluss（申请截止日期）
- 需要提交哪些材料

招聘信息里的 `Muss`、`erforderlich`、`Voraussetzung` 通常表示比较重要的硬性要求；wünschenswert、von Vorteil 一般表示有更好，但不一定是必须。

## 2. 准备 Bewerbung-Unterlagen

德国常见的申请材料包括：

- Lebenslauf（简历）
- Anschreiben（求职信）
- Zeugnisse（学历、成绩或工作证明等）
- Arbeitszeugnisse（工作证明）
- Praktikumszeugnisse（实习证明）
- 其他职位要求的材料

不是每份申请都需要全部材料。以招聘信息明确要求的文件为准。

Lebenslauf 和 Anschreiben 的具体写法见 [0013 CV_and_Cover_Letter](0013_CV_and_Cover_Letter.md)。

## 3. 找到正确的申请渠道

常见方式有：

| 方式 | 说明 |
|---|---|
| Unternehmenswebsite | 公司官网的 Karriere / Jobs 页面直接申请 |
| Karriereportal | 公司自己的在线招聘系统 |
| Jobbörse | 通过招聘平台提交 |
| E-Mail | 按招聘信息发送到指定邮箱 |
| LinkedIn | 部分职位可以直接申请 |
| 推荐 | 通过 Mitarbeiter-Empfehlung 等内部渠道申请 |

如果招聘信息明确要求通过公司的 Karriereportal 申请，通常就按照该方式提交，不需要再单独发一封邮件。

## 4. Online-Bewerbung

现在很多德国公司使用 Bewerbungsportal。

通常需要：

1. 注册账号
2. 填写个人信息
3. 上传 Lebenslauf
4. 上传 Anschreiben 和其他证明材料
5. 填写学历、工作经历等信息
6. 回答公司提出的问题
7. 检查资料
8. 提交 Bewerbung

提交前检查姓名、联系方式、时间、职位名称和附件是否正确。特别是 Anschreiben 不要把上一份申请的公司名称或职位留下。

## 5. Bewerbung 之后

提交申请后，一般可能出现几种情况：

- Absage：拒绝
- Einladung zum Vorstellungsgespräch：邀请面试
- Rückfragen：公司要求补充信息
- Zwischenstand：告知申请仍在处理中
- Einstellung / Zusage：录用

有些公司会自动发送 Eingangsbestätigung，表示已经收到申请。这不等于已经通过筛选。

如果一段时间没有消息，可以发送 höfliche Nachfrage（礼貌询问），确认 Bewerbung 的处理状态。

## 6. 面试阶段

如果公司对申请感兴趣，通常会邀请面试。可能的形式包括：

- Telefoninterview
- Videointerview
- Vorstellungsgespräch
- 多轮面试
- Assessment Center
- Probearbeit / Probetag（部分职位）

面试中常见内容包括自我介绍、学习和工作经历、申请这个职位的原因、专业技能、工作时间以及入职时间等。

具体面试准备见 [0014 Job Interviews](0014_Job_Interviews.md)。

## 7. Zusage 和 Arbeitsvertrag

收到口头或邮件上的 Zusage 后，通常还需要签署 Arbeitsvertrag。在正式接受工作前，可以确认：

- Gehalt
- Arbeitszeit
- Arbeitsbeginn
- Urlaub
- Probezeit
- Befristung
- Kündigungsfrist
- 工作地点
- Überstunden
- 其他合同条件

Arbeitsvertrag 的具体内容见 [0005 Employment Contract](0005_Employment_Contract.md)。

需要注意：`Zusage`、`Arbeitsvertrag` 和实际入职是不同的环节。具体法律关系取决于双方已经达成的协议和合同内容。

## 8. 如果被拒绝

收到 Absage 很正常，也不代表申请材料一定有问题。公司可能在申请人数、职位要求、招聘流程等方面做出选择。

如果希望了解原因，可以礼貌询问是否能够提供简短的反馈，但公司不一定会详细说明。

可以继续使用同一套基础 Bewerbung-Unterlagen 申请其他职位，但每次都应根据职位修改 Lebenslauf、Anschreiben 和申请重点。

## 9. 学生申请工作的常见组合

学生在德国找工作时，常见职位包括：

- Werkstudent
- Studentische Aushilfe
- Minijob
- Teilzeit
- Praktikum
- HiWi
- Tutor
- Ferienjob

具体工作形式和保险、工资、税务规则不同，不能只看职位名称判断。

## 10. 一份完整 Bewerbung 的流程

可以简单理解为：

Stellenanzeige → Unterlagen vorbereiten → Bewerbung einreichen → Rückmeldung → Vorstellungsgespräch → Zusage/Absage → Arbeitsvertrag → Arbeitsbeginn

不同公司可能省略其中某些环节，也可能增加测试、第二轮面试或其他筛选步骤。
