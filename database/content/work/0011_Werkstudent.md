# 德国 Werkstudent｜Werkstudent

Werkstudent 是德国大学生常见的就业形式。它不是单纯的“每周20小时工作”，而是学生身份、工作时间和社会保险规则结合起来的一种就业状态。只要仍然是正常在读学生，并且学习仍是主要活动，在满足相关条件时，就可能适用 Werkstudentenprivileg。

## 1. 谁可以做 Werkstudent

通常需要保持正式的学生身份，例如在 Universität 或 Hochschule 注册学习。仅仅有学生证并不代表任何情况下都能按照 Werkstudent 处理。如果已经毕业、处于特殊休学状态，或者工作已经成为主要活动，就需要重新判断是否还满足条件。

## 2. 20小时规则

Vorlesungszeit 期间，每周工作不超过20小时是最常见的判断标准。少于20小时当然也可以。

⭕️ 超过20小时并不一定马上失去 Werkstudent 身份。例如在 Semesterferien 工作时间增加，或者工作主要安排在晚上、周末，在满足相关条件时仍可能适用 Werkstudentenprivileg。
⭕️ 关键不是某一周单独超过20小时，而是整体工作安排是否仍符合学生身份的要求。

## 3. Werkstudent 的社会保险

如果符合 Werkstudentenprivileg，这份工作通常不产生普通 Arbeitnehmer 的 Krankenversicherung、Pflegeversicherung 和 Arbeitslosenversicherung 缴费，但 Rentenversicherung 通常仍然需要缴纳，工作期间也有法定 Unfallversicherung。

❗️所以“Werkstudent 不交社保”是不准确的。更准确地说，是部分社会保险项目因为学生身份而不需要通过这份工作缴纳。

| 保险 | Werkstudent 通常情况 |
|---|---|
| Krankenversicherung | 不因这份工作产生强制缴费 |
| Pflegeversicherung | 不因这份工作产生强制缴费 |
| Rentenversicherung | 通常需要缴费 |
| Arbeitslosenversicherung | 不因这份工作产生强制缴费 |
| Unfallversicherung | 有法定工伤保险 |

❗️OMA小提醒：不通过 Werkstudent 工作缴纳 Krankenversicherung，不代表学生没有医疗保险。学生仍然需要通过学生医疗保险、家庭保险或其他方式保持 Krankenversicherung。

## 4. Werkstudent 没有603欧元收入上限

603 € / Monat 是2026年的 Minijob 收入上限，不是 Werkstudent 的收入上限。

Werkstudent 可以赚800欧元、1,500欧元甚至更高，只要仍然满足 Werkstudent 的相关条件。


👉 Minijob → 重点看收入上限

👉 Werkstudent → 重点看学生身份和工作安排



## 5. Werkstudent 和 Teilzeit

Teilzeit 描述的是工作时间，Werkstudent 描述的是学生就业身份和相关社会保险规则，所以两者可以同时成立。

例如：Werkstudent + Teilzeit + befristet 表示学生工作 + 兼职 + 固定期限。

## 6. Werkstudent 和 Studentische Aushilfe

Studentische Aushilfe 通常只是招聘岗位名称，不代表固定的法律就业形式。

一份 Studentische Aushilfe 可能实际是：

- Werkstudent
- Minijob
- Teilzeit

所以最终要看 Arbeitsvertrag、工资、工作时间和 Beschäftigungsart。

## 7. Semesterferien 可以多工作吗？

可以。在符合相关条件的情况下，学生可以在 Semesterferien 增加工作时间，例如平时每周20小时，假期期间安排更多小时。

但不能简单理解成“假期想工作多少都可以”。如果长期大量工作，仍然需要判断学习是否还是主要活动。

## 8. Werkstudent 可以加班吗？

可以存在加班，但如果长期明显超过原本的工作时间，特别是在 Vorlesungszeit 长期超过20小时，就需要重新判断是否还能适用 Werkstudentenprivileg。

因此合同写20小时，并不意味着实际长期工作30小时也一定没有问题。

## 9. Werkstudent 和 Minijob

两者都很常见，但逻辑不同。

Werkstudent 没有603欧元收入上限，重点是学生身份和 Werkstudentenprivileg；Minijob 主要是收入较低的就业形式，2026年收入上限为603欧元/月，而且 Rentenversicherung 原则上需要缴纳，可以申请免除。

如果一个学生同时有 Werkstudent 和 Minijob，还需要把两份工作一起考虑，包括工作时间、税务和社会保险。

## 10. Werkstudent 的税

Werkstudent 并不免税。工资仍可能涉及 Lohnsteuer、Solidaritätszuschlag 和 Kirchensteuer，实际扣多少取决于工资、Steuerklasse 和个人情况。

如果一年中预扣的 Lohnsteuer 高于最终应缴税额，之后进行 Einkommensteuererklärung 时可能获得退税。

## 11. 毕业以后还能做 Werkstudent 吗？

一般不能因为之前是学生就继续保持 Werkstudent 身份。完成学业后，需要根据新的身份重新判断，例如转为 Vollzeit、Teilzeit 或其他就业形式。

如果之后开始新的符合条件的学习，则需要重新判断。

## 12. 国际学生

非欧盟学生除了满足 Werkstudent 的劳动和社会保险条件，还需要确认自己的 Aufenthaltstitel 是否允许相应工作。

Werkstudentenprivileg 和居留法是两套不同的规则。

## 13. 判断一份工作是不是 Werkstudent

可以简单看这几个问题：

1. 现在是否正式在读？
2. 学习是否仍然是主要活动？
3. Vorlesungszeit 每周工作多少小时？
4. 是否有 Semesterferien 的特殊工作安排？
5. 是否还有其他工作？
6. 是否满足 Werkstudentenprivileg？

确定之后，再判断 Krankenversicherung、Pflegeversicherung、Rentenversicherung 和 Arbeitslosenversicherung 怎么处理。
