# Germany OS 的目标

Germany OS 希望成为一个真正可以长期使用的：

> **德国生活与学习知识系统。**

不是把所有内容一次性堆在一起，而是建立清晰的结构：

**德国 → 教育 / 城市 / 租房 / 工作 / 生活 / 医疗 / 金融 / 签证 / 交通 / 娱乐**

再从每个大类进入具体主题。

最终让一个刚来到德国的人，可以从：

> “我不知道德国有什么”

一路找到：

> “我现在应该做什么、去哪里做、怎么做。”
