# 德国大学目录｜German Universities Directory

德国高校数量很多，而且不同高校的类型、专业优势、城市环境和申请要求差异很大。如果你已经了解了 Universität、TU、HAW、FH、TH 等高校类型，那么下一步就是找到**具体有哪些大学，以及它们分别在哪里、有什么特点**。

本页面作为德国高校总目录，主要用于：

- 快速查找德国主要高校
- 按城市查看高校
- 按高校类型了解 Universität、TU、HAW/FH 等
- 进入具体大学的详细介绍
- 进一步了解专业、申请、学习和考试等信息

> **说明：** 本目录不是德国所有高校的完整法律名录，而是 Germany OS 为德国留学与生活信息整理的主要高校导航。高校名称、类型、专业和申请要求可能发生变化，申请前应以学校官网及 Hochschulkompass 的最新信息为准。

## 一、德国高校怎么分类？

| 类型 | 德语 | 主要特点 |
|---|---|---|
| 综合性大学 | Universität | 理论、科研和学术导向较强，专业范围通常较广 |
| 工业大学 | Technische Universität（TU） | 属于 Universität 类型，重点发展工程、自然科学、技术等领域 |
| 应用科学大学 | Hochschule für angewandte Wissenschaften（HAW） | 实践和应用导向较强 |
| 应用科学大学 | Fachhochschule（FH） | 传统名称，强调实践和职业应用 |
| 艺术类高校 | Kunsthochschule | 艺术、设计等专业为主 |
| 音乐类高校 | Musikhochschule | 音乐、表演等专业为主 |

# 四、在哪里查德国大学？

如果需要查询德国高校的完整信息，推荐优先使用官方或专业数据库。

### Hochschulkompass

德国高校信息的重要官方入口之一，可以查询：

- 德国高校
- 高校类型
- 专业
- 学位
- 博士相关信息
- 高校基本信息

官网：

https://www.hochschulkompass.de/

### DAAD

德国学术交流中心（DAAD）提供德国高校和国际学生相关信息，也可以用于查找德国高校及专业。

官网：

https://www.daad.de/
