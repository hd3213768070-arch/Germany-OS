# 简介

LMU（慕尼黑大学）拥有多个官方平台。

每个平台负责不同的功能。

新生通常会因为不了解各个平台用途而影响学习效率。

本文用于介绍 LMU 官方系统之间的关系，并作为所有 LMU 官方平台知识的导航页。

---

# LMU 官方系统

| 系统 | 主要功能 |
|------|---------|
| Moodle | 下载课件、课程学习 |
| LSF | 课表、选课、考试、成绩 |
| Portal | 校园资讯、学生邮箱 |
| Studentenkanzlei | 学籍管理 |
| Online-Portale | 自助服务 |
| Raumfinder | 查找教室 |
| Benutzerkonto | 密码、学生证 |

# 常见问题

Q：

LMU 为什么有这么多网站？

A：

不同平台负责不同业务，因此需要多个系统协同工作。

---

Q：

新生最需要登录哪些平台？

A：

Portal、Moodle、LSF。
