# Mental Health

心理健康与支持板块，面向在德国学习、生活与工作的中文用户。

本板块提供非诊断性科普、低风险自助支持与德国专业求助路径；不替代医生、心理治疗师或紧急服务。涉及心理危机时，内容应优先引导用户使用德国的专业或紧急支持渠道。

## Content Areas

- `mental-health-basics/`：情绪、压力、孤独、留学适应与倦怠等基础主题。
- `mental-disorders/`：常见心理疾病的非诊断性科普与可靠求助入口。
- `self-help/`：低风险自我支持、建立支持网络与何时升级求助。
- `germany-support/`：德国心理咨询、心理治疗、医保和大学/Studentenwerk 支持。
- `emergency/`：心理危机、自伤或自杀风险的紧急求助路径。

## Editorial Boundary

- 心理疾病科普不用于自我诊断。
- 不提供个体化诊断、治疗或用药建议。
- 医疗系统、医保、药物与常规预约规则以 `../healthcare/` 为主；具体大学咨询入口可链接至 `../university/` 的学校页面。
