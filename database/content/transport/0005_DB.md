## 🧭 一、DB 是什么？

Deutsche Bahn，简称 DB，是德国主要的铁路运输企业及铁路服务提供方。

日常生活中，你可能通过 DB 查询或购买以下交通服务：

- ICE 高速列车。
- IC 城际列车。
- EC 欧洲城际列车。
- 部分区域铁路及其他公共交通连接。
- 德国境内和部分跨境铁路行程。

需要注意，德国铁路系统并不完全由 DB 独家运营。部分区域列车由其他铁路公司运营，但仍可能出现在 DB 的路线查询结果中。

### DB 官网

官方网站：

https://www.bahn.de/

### DB Navigator 是什么？

DB Navigator 是 DB 的官方出行应用。

可以通过它查询行程、查看部分实时交通信息、购买车票及管理部分订单。

官方信息：

https://www.bahn.de/service/mobile/db-navigator

**简单理解：**

- DB 官网：适合在电脑上查询、比较和购买车票。
- DB Navigator：适合手机上查询行程、查看电子票和跟踪出行信息。

不同功能可能因平台、账户状态和车票类型而有所区别。

## 📱 二、如何查询火车时刻表？

在德国乘坐火车前，建议先通过 DB 查询路线。

### 第一步：打开查询页面

进入：

https://www.bahn.de/

也可以打开 DB Navigator。

### 第二步：填写出发地和目的地

常见字段：

| 德语 | 中文 | 示例 |
|---|---|---|
| Von | 从哪里出发 | München Hbf |
| Nach | 前往哪里 | Berlin Hbf |
| Hinfahrt | 去程 | 慕尼黑前往柏林 |
| Rückfahrt | 返程 | 柏林返回慕尼黑 |
| Datum | 日期 | 出行日期 |
| Uhrzeit | 时间 | 出发或到达时间 |
| Abfahrt | 出发 | 按出发时间查询 |
| Ankunft | 到达 | 按到达时间查询 |
| Reisende | 乘客 | 乘车人数 |
| Klasse | 座位等级 | 一等座或二等座 |

如果你希望在某个时间之前到达目的地，可以选择按照到达时间查询。

### 第三步：查看查询结果

查询结果通常会显示：

- 出发时间。
- 到达时间。
- 总旅行时间。
- 换乘次数。
- 列车类型。
- 预计票价。
- 部分线路的站台及实时运行信息。

### 第四步：比较不同路线

不要只选择价格最低的行程，还应检查：

1. 是否需要换乘。
2. 换乘时间是否充足。
3. 是否需要在不同车站之间移动。
4. 是否存在施工或延误提示。
5. 车票是否适用于全部行程。
6. 预计到达时间是否符合安排。

如果你需要参加考试、赶飞机或参加重要活动，建议为延误和换乘预留额外时间。

## 🎫 三、DB 的火车票有哪些类型？

德国长途火车票的价格和使用条件可能存在明显差异。

常见票种包括 Sparpreis、Super Sparpreis 和 Flexpreis。

### 1. Super Sparpreis：特价优惠票

Super Sparpreis 通常属于限制较多的优惠票。

特点：

- 部分线路和日期可能有较低价格。
- 通常绑定指定的长途列车。
- 退票和改签限制较严格。
- 通常不能像灵活票一样随意更改出行时间。

购买前应查看具体订单的退改规则。

如果你已经确定出行日期，而且希望尽可能降低票价，可以比较这类车票。

### 2. Sparpreis：优惠票

Sparpreis 也是优惠票，通常比灵活票便宜，但会受到具体票价条件限制。

与 Super Sparpreis 相比，两者的退票条件可能不同。

不要只凭名称判断哪张票更适合自己，应直接查看购票页面中的具体条款。

### 3. Flexpreis：灵活票

Flexpreis 通常提供更大的出行灵活性。

具体条件取决于票种和行程，可能允许在规定范围内选择适用的列车，而不必像部分优惠票一样严格绑定单一班次。

但需要注意：

- Flexpreis 不代表可以无限制乘坐所有列车。
- 仍然需要遵守票面规定、适用线路和有效期。
- 不同票种及行程的退改规则可能不同。

### 4. 一等座和二等座

购票时通常可以选择：

- 2. Klasse：二等座。
- 1. Klasse：一等座。

二等座通常适合大多数普通旅行。

一等座可能提供更宽敞的座位或不同的车厢服务，但具体设施因列车而异。

购买前应比较价格差异和实际需求。

### 5. 单程票和往返票

常见表达：

- Einfache Fahrt：单程。
- Hin- und Rückfahrt：往返。

购买往返行程时，可以比较分开购买和同一订单购买的价格与条件。

不同订单的退改规则可能不同，不能只根据是否属于同一订单来判断能否退款。

## 💶 四、如何在 DB 上买火车票？

以下是一般购票流程。

### 第一步：查询行程

填写出发地、目的地、日期、时间和乘客人数。

### 第二步：选择合适的班次

比较不同班次的：

- 票价。
- 出发及到达时间。
- 换乘次数。
- 总旅行时间。
- 车票条件。

### 第三步：选择票价

确认自己选择的是哪一种票价，例如 Super Sparpreis、Sparpreis 或 Flexpreis。

特别注意退票和改签条件。

### 第四步：检查乘客信息

根据页面要求填写或确认乘客信息。

如果购买实名车票，应确保姓名等信息准确。

### 第五步：选择座位预订

系统可能提供额外的座位预订选项。

座位预订通常与车票本身是不同的项目，是否包含在价格内取决于具体票种和销售条件。

### 第六步：付款

根据页面提供的支付方式完成付款。

可用方式可能包括银行卡、信用卡或其他数字支付方式，具体取决于销售渠道和账户条件。

### 第七步：保存车票

购买完成后，检查：

- 订单是否成功。
- 车票是否已经生成。
- 出发日期和时间是否正确。
- 出发站及目的地是否正确。
- 车票类型和适用条件。
- 是否已经收到确认邮件。

如果使用电子票，建议提前在 DB Navigator 或相应订单页面确认车票可以正常显示。

**注意：付款成功的提示与已经取得可用车票并不是完全相同的概念。出发前应确认订单和车票状态。**

## 💺 五、座位预订 Sitzplatzreservierung

购买火车票时，可能会看到 Sitzplatzreservierung，即座位预订。

### 1. 买了火车票，一定有座位吗？

不一定。

**车票与座位预订是两个不同的概念。**

在通常情况下，持有有效车票并不意味着一定有指定座位。

如果你没有预订座位，可能需要寻找空余座位，也可能遇到车厢较拥挤的情况。

### 2. 哪些情况建议预订座位？

以下场景可以考虑预订：

- 周末或节假日出行。
- 长距离旅行。
- 携带较多行李。
- 多人一起旅行，希望坐在一起。
- 需要长时间乘车。
- 不希望上车后寻找座位。

### 3. 座位预订多少钱？

价格取决于当前适用的预订规则、列车及具体产品。

购买前应查看订单页面显示的实际费用。

不要假定所有车票都包含座位预订，也不要假定所有列车的预订价格相同。

### 4. 座位预订后，车票还能退吗？

需要区分车票和座位预订的退改规则。

即使某张车票可以退改，座位预订费用也可能适用不同的条件。

应查看订单中的具体说明。

### 5. 如何找到自己的座位？

通常需要查看：

- Wagen：车厢。
- Sitzplatz：座位。
- Wagenreihung：列车编组信息。

车票或座位预订信息可能显示车厢和座位编号。

上车前可以查看站台显示屏，确认列车编组和车厢停靠位置。

如果列车临时改变编组，应以现场信息为准。

## 🎒 六、德国火车可以带多少行李？

乘坐德国铁路时，通常可以携带适合自行搬运并妥善放置的行李，但具体限制可能因服务和列车而异。

### 行李注意事项

- 尽量将行李放在指定行李架或座位上方的行李空间。
- 不要堵塞过道、车门或紧急通道。
- 不要占用其他乘客的座位放置行李。
- 大件行李应提前考虑搬运和存放问题。
- 如果需要携带自行车、特殊设备或其他大件物品，应查看对应的运输规定。

如果购买的是长途巴士或飞机票，行李规则可能完全不同，不能将 DB 的规则直接套用到其他交通工具。

## 🔄 七、火车票可以退票或改签吗？

这取决于你购买的具体票种。

德国铁路的不同票价可能具有不同的取消、退款和改签条件。

### 1. Super Sparpreis

通常限制较多，往往不能像灵活票一样随意取消并获得退款。

如果购买后发现日期错误，应立即检查订单条款及是否存在适用的例外规则。

### 2. Sparpreis

通常也有一定限制，但可能存在与 Super Sparpreis 不同的退票条件。

应以订单中显示的具体规则为准。

### 3. Flexpreis

通常具有更大的灵活性，但仍然需要遵守适用的退票期限、手续费及其他条件。

### 4. 如何取消或修改订单？

如果通过 DB 官网或 DB Navigator 购买，可以尝试以下步骤：

1. 登录购买时使用的账户。
2. 打开订单或旅行计划。
3. 找到对应车票。
4. 查看是否提供取消、退款或修改选项。
5. 阅读系统显示的费用和限制。
6. 确认操作。
7. 保存处理结果。

如果没有登录账户购买，可能需要使用订单确认信息或预订编号查找订单。

### 5. 哪些情况需要特别注意？

- 出发日期填写错误。
- 购买了不适合自己的票种。
- 需要提前结束旅行。
- 需要更换出发时间。
- 车票已经开始使用。
- 车票属于特殊优惠产品。

不要在没有确认规则的情况下直接取消订单，因为部分操作可能无法撤销。

官方信息：

https://www.bahn.de/

## 🚨 八、德国火车延误或取消怎么办？

德国铁路旅行中，可能遇到列车延误、取消、站台变更或施工。

常见德语提示：

| 德语 | 中文 |
|---|---|
| Verspätung | 延误 |
| Zugausfall | 列车取消 |
| Gleisänderung | 站台变更 |
| Abfahrt | 出发 |
| Ankunft | 到达 |
| Ersatzverkehr | 替代交通 |
| Anschluss | 后续连接或换乘 |
| Anschlusszug | 后续换乘列车 |
| Wagenreihung | 列车编组信息 |

### 1. 出发前查看实时信息

建议在出发前和到达车站后分别确认：

- 列车是否正常运行。
- 实际出发时间。
- 站台是否改变。
- 是否需要换乘。
- 后续连接是否仍然有效。

不要只依赖最初保存的行程截图。

### 2. 列车取消怎么办？

如果列车被取消，应查看 DB 或负责运营商提供的替代方案。

可能包括：

- 乘坐其他适用列车。
- 更换行程。
- 通过替代交通继续出行。
- 根据具体条件申请退款或其他旅客权利。

但并不是所有票种和行程都适用完全相同的规则。

### 3. 错过换乘怎么办？

应先确认你的车票是否覆盖整段联程行程，以及当前票种和具体情况适用什么规则。

如果后续列车是另外购买的独立车票，前一段延误不一定自动赋予你使用后一张车票的权利。

遇到问题时，可以通过 DB 的实时信息和客服渠道确认可行方案。

### 4. 可以申请补偿吗？

在符合条件的情况下，铁路乘客可能享有相应的旅客权利，例如特定情况下的票价补偿。

是否符合条件，取决于延误程度、行程情况、票种以及适用规定。

建议保存：

- 车票。
- 订单确认。
- 实际到达时间。
- 延误或取消通知。
- 相关额外支出凭证。

然后按照官方流程提交申请。

官方信息：

- [DB｜乘客权利与补偿](https://www.bahn.de/service/informationen-buchung/fahrgastrechte)
- [欧盟｜铁路乘客权利](https://europa.eu/youreurope/citizens/travel/passenger-rights/rail/index_en.htm)

## 📲 九、DB Navigator 怎么用？

DB Navigator 是德国铁路常用的手机应用。

它的功能可能随版本更新而变化，但常见用途包括：

- 查询火车时刻表。
- 规划路线。
- 查看车次信息。
- 查看部分实时运行信息。
- 购买车票。
- 显示电子票。
- 查看部分订单和旅行信息。

### 1. 出发前

建议检查：

- 车票是否可以正常显示。
- 列车是否按计划运行。
- 出发站台是否发生变化。
- 是否需要换乘。
- 是否有其他运行通知。

### 2. 旅行途中

如果出现延误，可以查看应用中的最新行程信息。

但应注意，应用显示的信息可能随实际运行情况更新。

如果涉及紧急换乘或行程变更，应同时留意车站显示屏和现场广播。

### 3. 是否必须注册账户？

具体功能和购买方式可能有所不同。

部分购票流程可能允许不登录账户完成购买，但账户通常有助于管理订单和旅行信息。

购买前应确认自己的车票如何保存、如何重新获取，以及遗失订单信息后如何查询。

## 🧾 十、DB 订单、电子票和付款常见问题

### 1. 付款成功，但没有收到车票怎么办？

建议依次检查：

1. 是否收到订单确认邮件。
2. 邮件是否进入垃圾邮件文件夹。
3. DB 账户中是否显示订单。
4. 银行账户是否出现扣款或待处理交易。
5. 是否存在重复下单的可能。

如果仍然无法确认订单状态，应联系销售平台客服。

不要在没有核实订单的情况下反复付款，以免产生重复订单。

### 2. 电子票找不到怎么办？

如果通过账户购买，可以登录原账户检查订单。

如果没有登录账户购买，应查找确认邮件和订单信息，并按照 DB 的官方流程处理。

### 3. 可以把电子票截图给别人用吗？

不要这样做。

实名电子票通常与指定乘客相关，不能随意转让。

如果其他人需要出行，应根据其实际情况购买适用车票。

### 4. 银行卡扣款了，但订单取消了怎么办？

应先确认订单状态及扣款类型。

有些交易可能只是待处理授权，并不一定代表最终扣款。

如果确认出现重复扣款或退款异常，应联系销售方核实，并保留订单编号、交易记录和相关邮件。

### 5. 可以在车站买长途火车票吗？

部分车站设有售票机或 DB 服务中心，但服务设施和营业时间因车站而异。

如果行程重要，建议提前查询并购买车票，不要假设每个车站都有人工售票服务。

## ⚠️ 十一、使用 DB 最容易犯的错误

### 错误 1：只看价格，不看退改条件

便宜的优惠票可能有较严格的限制。

购票前应先确定行程是否固定，再选择适合的票种。

### 错误 2：认为买了票就一定有座位

车票与座位预订是不同的概念。

如果需要指定座位，应确认是否已经完成座位预订。

### 错误 3：把 Deutschlandticket 当作 ICE 车票

Deutschlandticket 通常不适用于 ICE、IC、EC 等长途列车。

如果需要乘坐这些列车，应确认自己是否拥有适用的车票。

### 错误 4：不检查站台变化

德国铁路可能发生临时站台调整。

出发前应查看最新信息，而不是只依赖旧截图。

### 错误 5：错过换乘后直接乘坐其他列车

即使原列车发生延误，也应确认当前票种和具体规则是否允许改乘其他列车。

### 错误 6：以为所有车票都能退款

退票和改签规则取决于具体票种。

购买前应查看条款，避免发生不必要的损失。

### 错误 7：忘记检查乘客信息

如果购买的是实名票，应确保姓名和相关信息准确。

### 错误 8：只保存截图，不保留订单信息

建议保留订单确认邮件、预订编号和可正常显示的电子票，以便发生问题时查询。

## ❓ 十三、常见问题 FAQ

### Q1：DB 和 DB Navigator 有什么区别？

DB 是 Deutsche Bahn 的简称；DB Navigator 是其官方出行应用之一。

### Q2：DB 可以查询所有德国火车吗？

DB 可以查询许多德国铁路行程，但具体信息和可购买服务可能因线路、运营商及销售渠道而异。

### Q3：Super Sparpreis 和 Flexpreis 有什么区别？

Super Sparpreis 通常更便宜，但限制较多；Flexpreis 通常更灵活。具体退改条件应以购买时显示的票价规则为准。

### Q4：没有预订座位，可以上 ICE 吗？

如果持有适用于该列车的有效车票，通常可以乘车，但不一定有指定座位。

### Q5：DB 车票可以退款吗？

取决于票种和具体情况。不同票价适用不同的退改规则。

### Q6：列车晚点了，能不能直接乘坐下一班车？

应先确认车票条件、行程安排和适用规则。不要假定所有车票都可以无条件改乘。

### Q7：DB Navigator 可以显示电子票吗？

如果你的车票支持在应用中显示，通常可以通过对应账户或订单查看。具体取决于购买方式和车票类型。

### Q8：Deutschlandticket 可以在 DB 上购买吗？

DB 是 Deutschlandticket 的销售渠道之一，但不同销售方的订阅管理和取消流程可能不同。具体规则请查看 [0002｜Deutschlandticket 指南](0002_Deutschlandticket.md)。

### Q9：可以在 DB 上购买国际火车票吗？

DB 提供部分国际铁路行程的查询和购票服务，但可购买路线和具体条件因目的地、运营商和销售渠道而异。

### Q10：遇到购票或退票问题应该找谁？

如果通过 DB 购买，通常应先联系 DB 或使用其官方订单管理及客服渠道。如果通过其他平台购买，应优先联系原销售方。
