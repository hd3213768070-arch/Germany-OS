## 🌍 一、外国驾照可以在德国使用多久？

首先需要区分两种情况：

- **短期停留德国**：例如旅游、短期访问。
- **在德国建立正常居住地**：例如长期留学、工作或家庭居住。

两种情况适用的规定可能不同。

### 1. 在德国短期停留

外国驾照能否使用，需要根据驾照签发国家、驾照形式及相关法律规定判断。

部分外国驾照可能需要搭配国际驾驶许可证或翻译文件使用。国际驾驶许可证通常不能脱离原始驾照单独使用。

出发前应确认：
- 原始驾照是否有效。
- 驾照类别是否覆盖计划驾驶的车辆。
- 是否需要国际驾驶许可证或认可的翻译件。
- 是否存在其他适用条件。

### 2. 在德国长期居住

对于通常居住地位于德国的人，非欧盟、非欧洲经济区驾照通常受到德国驾驶许可法规规定的期限限制。

一般而言，外国驾照在德国建立正常居住地后，通常可以在一定期限内继续使用；常见规则是**自建立正常居住地起六个月**。

但六个月规则并不是对所有外国驾照和所有情况都毫无例外。特殊情况、延长申请及其他适用条件应根据现行法律和主管部门的判断确认。

因此，如果你持中国驾照在德国留学或工作，应尽早核实：
- 主管部门认定的正常居住地起始时间。
- 驾照是否属于可在德国使用的有效外国驾照。
- 是否需要翻译或其他证明。
- 六个月期限是否适用于自己的具体情况。
- 是否可以申请延长使用期限。

**不要把德国入境日期、住址登记日期或居留卡签发日期直接视为所有情况下的唯一计算依据。** 具体应以适用法规及主管部门对个人情况的认定为准。

### 3. 六个月结束后怎么办？

如果外国驾照在德国的使用期限已经结束，不能仅仅因为原始驾照仍然有效，就认为可以继续在德国驾驶。

此时应确认自己是否已经取得德国驾驶许可，或者是否存在适用于个人情况的其他合法依据。

如果尚未取得德国驾照，不要在没有确认法律依据的情况下继续驾驶。

## 🇨🇳 二、中国驾照可以直接换成德国驾照吗？

**中国驾照可以申请换领德国驾照，但通常不能免除理论考试和实际驾驶考试。**

德国《驾驶许可条例》（Fahrerlaubnis-Verordnung，FeV）第 31 条及附件 11（Anlage 11）规定了外国驾照换领德国驾照的特殊条件。

截至本文编写时，中国大陆不在附件 11 的免试国家名单中。因此，持中国大陆驾照申请换领德国 B 类驾照，通常需要通过德国理论考试和实际驾驶考试。

官方依据：
- [德国《驾驶许可条例》FeV 第 31 条](https://www.gesetze-im-internet.de/fev_2010/__31.html)
- [德国《驾驶许可条例》附件 11：外国驾照换领特殊规定](https://www.gesetze-im-internet.de/fev_2010/anlage_11.html)

### 1. 换领和从零考驾照有什么区别？

对于持有有效中国驾照的人，换领申请与首次考取德国驾照并不完全相同。

| 项目 | 中国驾照换领德国驾照 | 首次考取德国驾照 |
|---|---|---|
| 是否需要申请 | 需要 | 需要 |
| 是否需要核验原有驾照 | 需要 | 不涉及原有驾照 |
| 理论考试 | 通常需要 | 需要 |
| 实际驾驶考试 | 通常需要 | 需要 |
| 是否必须完成全部常规驾校课程 | 不应直接认定必须全部重读 | 需要完成适用的培训要求 |
| 是否可以直接取得德国驾照 | 通常不可以 | 不可以 |

**重要：不需要完成全部常规培训，不等于可以不参加考试。**

对于不属于附件 11 免试国家的外国驾照持有人，德国法规在符合条件时允许免除部分常规培训要求，但理论考试和实际驾驶考试通常仍然需要参加。

具体申请要求、材料及考试安排应由当地 Fahrerlaubnisbehörde 确认。

### 2. 中国驾照换领德国驾照，需要重新上驾校吗？

不一定需要按照首次考驾照的方式完成全部培训，但建议联系驾校了解实际考试要求。

你可以选择：
- 直接咨询驾校，说明自己持有有效中国驾照，需要 Umschreibung。
- 了解理论考试报名及准备方式。
- 预约少量驾驶训练，熟悉德国道路规则和考试要求。
- 根据自己的驾驶水平决定是否增加训练课时。

即使你在中国已经有多年驾驶经验，也不代表能够直接通过德国实际驾驶考试。

德国考试对道路观察、优先通行规则、转弯、变道、速度控制、停车及危险识别等方面有明确要求。

## 📋 三、换领德国驾照需要准备什么材料？

具体材料由当地主管部门决定。以慕尼黑为例，申请前应查看慕尼黑市政府公布的外国驾照换领要求。

常见材料如下：

| 材料 | 德语 | 说明 |
|---|---|---|
| 护照 | Reisepass | 用于身份核验 |
| 居住登记证明 | Meldebescheinigung | 视主管部门要求提供 |
| 原始中国驾照 | Ausländischer Führerschein | 应当真实、有效 |
| 德语翻译件 | Übersetzung des Führerscheins | 是否需要及接受何种翻译，应以当地要求为准 |
| 证件照片 | Biometrisches Passfoto | 符合德国证件照片要求 |
| 视力检查证明 | Sehtest | 根据申请类别及主管部门要求办理 |
| 急救课程证明 | Nachweis über Erste-Hilfe-Kurs | 根据申请类别及适用规定确认 |
| 申请表 | Antragsformular | 按当地流程填写 |
| 其他证明 | Weitere Nachweise | 可能需要补充驾照真实性、有效性或其他相关证明 |

### 特别注意

1. **不要默认普通翻译件一定符合要求。** 应先确认主管部门接受的翻译形式及出具机构。
2. **不要在申请前就自行认定所有材料都必须提交。** 不同驾照类别和个人情况可能适用不同要求。
3. 如果中国驾照已经过期、属于临时驾照，或者曾经在德国建立正常居住地后才续发，需要特别确认是否符合换领条件。
4. 如果主管部门要求补充驾照真实性或有效性证明，应按照其要求办理。

### 慕尼黑官方申请入口

如果你在慕尼黑居住，可以从以下页面查询外国驾照换领的最新要求：

[慕尼黑市政府｜外国驾照换领德国驾照](https://stadt.muenchen.de/service/en-GB/info/fuhrerscheinstelle/10424591/)

建议在预约前仔细查看：
- 申请方式。
- 材料清单。
- 是否需要预约。
- 翻译件要求。
- 申请费用。
- 处理时间。

## 🏢 四、在慕尼黑办理换领，应该去哪里？

负责办理外国驾照换领的部门通常是 Führerscheinstelle，即驾驶许可主管部门。

在慕尼黑，应通过市政府官方页面确认办理地点和当前流程。

**不要直接把普通 Bürgerbüro 的业务流程等同于驾照换领流程。** 不同业务可能由不同部门负责。

### 推荐办理顺序

1. 打开慕尼黑市政府外国驾照换领页面。
2. 确认自己申请的是普通 B 类驾照还是其他类别。
3. 阅读材料要求。
4. 确认是否需要预约或在线申请。
5. 按要求提交材料。
6. 等待主管部门审核。
7. 根据要求完成理论考试和实际驾驶考试。
8. 按主管部门通知领取德国驾照。

如果申请过程中遇到不明确的材料要求，应直接向主管部门确认，不要仅依据驾校或网上论坛的经验判断。

## 📝 五、换领德国驾照的完整流程

### 第一步：确认中国驾照是否符合换领条件

首先确认：
- 驾照是否真实有效。
- 驾照类别是否与申请的德国驾照类别对应。
- 驾照是否在合法情况下取得。
- 是否存在临时驾照、过期或续发时间等特殊情况。
- 是否需要额外的真实性或有效性证明。

如果不确定，可以先联系当地主管部门。

### 第二步：准备材料

按照当地要求准备原始驾照、身份文件、照片、翻译件及其他证明。

建议在提交前核对每份文件的有效期和格式。

### 第三步：提交申请

向当地驾驶许可主管部门提交 Umschreibung 申请。

申请提交后，主管部门可能需要核实外国驾照的真实性及有效性。

**提交申请不代表换领已经获批，也不代表原有驾照在德国的使用期限自动延长。**

### 第四步：联系驾校并准备考试

确认需要参加的理论考试和实际驾驶考试。

可以根据自己的情况选择驾校，并了解：
- 报名费用。
- 理论学习安排。
- 驾驶训练课时费用。
- 考试车辆及考试服务费用。
- 考试预约方式。
- 补考费用。

如果你已经熟悉德国道路规则，可以先评估自己的实际驾驶能力，再决定训练课时。

### 第五步：参加理论考试

中国大陆驾照持有人换领普通德国 B 类驾照时，通常需要通过理论考试。

应确认考试语言、预约方式和考试费用。

理论考试的具体题型、备考方法及常见错误，请查看 [0011｜德国驾照考试指南](0011_Driving_License_Exams.md)。

### 第六步：参加实际驾驶考试

在满足申请和考试条件后，参加实际驾驶考试。

建议提前熟悉德国交通规则，尤其是：
- 右侧通行和优先通行。
- 交通标志与限速。
- 路口观察。
- 转弯和变道。
- 行人与自行车的通行权。
- 停车和倒车。
- 高速公路及其他道路的安全驾驶。

### 第七步：领取德国驾照

在满足换领及考试要求后，按照主管部门通知领取德国驾照。

慕尼黑市政府的官方说明指出，领取德国驾照时，通常需要交回外国驾照。

因此，办理前应确认原始中国驾照将如何处理，以及领取德国驾照时需要携带什么文件。

## ⏳ 六、换领需要多长时间？

德国驾照换领没有适用于所有申请人的统一办理时长。

整个过程可能受到以下因素影响：
- 当地主管部门的申请量。
- 材料是否完整。
- 是否需要核实外国驾照。
- 是否需要补交证明。
- 驾校的理论课程及驾驶训练安排。
- 理论考试和实际考试的预约情况。
- 是否需要补考。

建议尽早提交申请，不要等到中国驾照在德国的使用期限即将结束才开始办理。

如果需要在德国合法驾驶，应同时确认当前驾照的使用期限，不要把申请处理中理解为自动获得继续驾驶的许可。

## 💶 七、换领德国驾照需要多少钱？

换领总费用取决于当地行政收费、翻译服务、驾校收费和考试次数。

常见费用包括：

| 费用项目 | 德语 | 说明 |
|---|---|---|
| 行政申请费 | Verwaltungsgebühr | 主管部门收取 |
| 驾照翻译费 | Übersetzungskosten | 视文件和翻译要求而定 |
| 视力检查费 | Sehtest | 适用时产生 |
| 急救课程费用 | Erste-Hilfe-Kurs | 适用时产生 |
| 驾校报名费 | Grundbetrag | 取决于驾校 |
| 理论考试费 | Theorieprüfungsgebühr | 通常需要参加理论考试 |
| 实际考试费 | Praktische Prüfungsgebühr | 通常需要参加实际驾驶考试 |
| 驾驶训练费 | Fahrstunden | 根据个人水平决定 |
| 考试车辆及服务费 | Vorstellung zur Prüfung | 依驾校收费标准而定 |
| 补考费用 | Wiederholungsprüfung | 未通过考试时可能产生 |

**不要把换领行政申请费当作全部费用。**

如果你已经有中国驾照，但需要参加两项考试，实际支出仍可能包括驾校费用、训练课时和考试费用。

建议同时向主管部门和驾校索取费用清单，再估算总预算。

## ⚠️ 八、几个容易出错的问题

### 1. 中国驾照有效，就可以一直在德国开车吗？

不可以直接这样理解。

在德国建立正常居住地后，外国驾照的使用通常受到期限限制。中国驾照持有人应核实适用的六个月规则及个人情况。

### 2. 已经提交换领申请，就可以继续开车吗？

不一定。

提交申请本身通常不会自动延长外国驾照的使用期限。应确认自己是否仍然具备在德国合法驾驶的条件。

### 3. 中国驾照可以免考吗？

中国大陆不在德国 FeV 附件 11 的免试国家名单中。因此，换领普通 B 类驾照时，通常需要参加理论考试和实际驾驶考试。

### 4. 换领是不是必须重新读完整个驾校课程？

不能简单地说必须全部重读。

符合条件的外国驾照换领申请可能适用不同于首次考驾照的培训要求，但考试要求仍然需要满足。

### 5. 中国驾照翻译件可以代替原始驾照吗？

不能默认可以。

翻译件通常是辅助文件，不应直接当作原始驾驶资格证明。应按照主管部门要求提供原始驾照及相应文件。

### 6. 中国驾照过期后，还可以申请换领吗？

不能直接认定可以。

过期驾照可能不符合换领条件，具体需要由主管部门根据驾照状态及适用法规判断。

### 7. 可以在德国换领驾照后保留中国驾照吗？

通常需要在领取德国驾照时交回外国驾照。具体处理方式应向主管部门确认。

### 8. 换领德国驾照后，可以在中国开车吗？

德国驾照是否能在中国使用，需要根据中国当地的法律及驾驶许可要求判断。德国驾照不能自动替代中国驾驶许可。
