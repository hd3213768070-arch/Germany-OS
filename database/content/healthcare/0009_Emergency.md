# 0009｜德国医疗急诊 Emergency

在德国，遇到突然严重的身体问题时，最重要的是先判断：这是普通医疗问题、需要尽快处理的问题，还是可能危及生命的紧急情况。

不同情况对应的处理方式不一样。最常见的几个概念是 112、Notaufnahme 和 116117。

## 一、112：真正的紧急情况

112 是德国的紧急救援电话。

如果情况可能危及生命，应该直接拨打 112。

例如：

- 严重呼吸困难
- 意识丧失
- 心脏骤停
- 严重胸痛
- 严重事故
- 大量出血
- 严重过敏反应
- 突发严重症状，怀疑危及生命

拨打 112 后，接线人员会询问发生了什么、在哪里以及目前的情况，并根据情况安排急救。

如果不确定情况是否危及生命，但症状非常严重，也不要因为担心“是不是不够严重”而延误求助。

## 二、Notaufnahme：医院急诊

Notaufnahme 是医院里的急诊部门。

它主要处理需要紧急医疗评估和治疗的问题。

例如：

- 严重外伤
- 突然出现的严重症状
- 需要马上进行检查或治疗的问题
- 无法等待普通门诊处理的情况

但 Notaufnahme 不是普通的“无预约门诊”。

如果只是：

- 普通感冒
- 轻微咳嗽
- 一般性的轻微疼痛
- 可以等待正常预约处理的问题

通常不需要直接去 Notaufnahme。

## 三、116117：非生命危险的医疗帮助

116117 是德国医疗值班服务。

它主要用于：

**有医疗问题，需要尽快获得帮助，但没有明显生命危险。**

例如：

- 医生诊所已经关门
- 突然生病，无法等到普通门诊
- 不知道应该去哪里看医生
- 需要医疗建议
- 需要寻找医疗服务

116117 可以根据情况提供医疗建议，并帮助判断下一步应该怎么处理。

部分地区还可以通过 116117 的网站或相关服务寻找医生和预约。

## 四、112、116117 和 Notaufnahme 怎么区分？

可以简单理解：

**可能危及生命 → 112**

**需要紧急医疗处理，但没有明显生命危险 → 116117 / 合适的医疗服务**

**需要医院紧急治疗 → Notaufnahme**

三者并不是完全互相替代的。

如果情况危及生命，不应该因为想先咨询 116117 而耽误拨打 112。

## 五、普通生病怎么办？

如果只是普通疾病，通常可以先联系 Hausarzt。

例如：

- 感冒
- 咳嗽
- 普通发烧
- 轻微肠胃不适
- 一般头痛
- 一般性疼痛

可以：

**Hausarzt → 检查 → 治疗 / 处方 / 必要时转诊**

如果 Hausarzt 不营业，而你又觉得问题不能等到下一次正常门诊，可以考虑联系 116117。

## 六、什么情况下应该马上处理？

如果出现突然、严重或者快速恶化的症状，不应该只是等待普通预约。

例如：

- 呼吸明显困难
- 意识状态异常
- 突然失去意识
- 严重胸痛
- 大量出血
- 严重外伤
- 突然出现严重神经系统症状
- 严重过敏反应

这些情况可能需要立即医疗处理。

如果怀疑存在生命危险，应拨打 112。

## 七、急诊是不是谁先到谁先看？

不是。

Notaufnahme 通常会根据患者的病情严重程度进行分诊和处理。

因此：

**先到 ≠ 一定先看**

如果另一名患者的情况更加紧急，即使对方比你晚到，也可能优先接受治疗。

所以在急诊等待较长时间，并不一定代表医院没有处理你的情况。

## 八、去 Notaufnahme 需要预约吗？

通常不需要像普通诊所一样提前预约。

如果确实存在需要急诊处理的问题，可以直接前往医院的 Notaufnahme。

但如果只是普通疾病，最好使用 Hausarzt、Facharzt 或 116117 等更合适的医疗服务。

## 九、去急诊需要带什么？

如果情况允许，可以带：

- Gesundheitskarte
- 身份证件
- 正在服用的药物信息
- 过敏信息
- 重要医疗记录
- 以前的检查结果

但如果是严重紧急情况，不要因为没有带齐这些东西而延误就医。

## 十、到了急诊以后会发生什么？

通常可能经历：

**到达 → 登记 → 分诊 → 医生评估 → 检查 → 治疗 → 回家 / 住院 / 转其他科室**

根据情况可能进行：

- 血液检查
- 心电图
- X 光
- CT
- 超声
- 其他必要检查

具体检查由医疗团队根据病情决定。

## 十一、急诊以后可能有哪几种结果？

完成评估后，可能：

- 治疗后回家
- 开药
- 建议联系 Hausarzt
- 建议预约 Facharzt
- 安排进一步检查
- 住院
- 转到其他医院或专科

所以去 Notaufnahme 并不意味着一定会住院。

## 十二、GKV 看急诊需要自己付钱吗？

如果你参加 GKV，符合医保保障范围的急诊和医院治疗通常由医保承担。

但住院等情况下可能涉及法定 Zuzahlung，某些额外服务也可能产生费用。

如果医生或医院提供额外的自费服务，可以提前确认费用和医保承担范围。

## 十三、如果只是想“快一点”，不要随便去急诊

急诊的主要目的是处理紧急医疗问题。

如果只是因为：

- 普通诊所预约太难
- 不想等待
- 想马上做普通检查
- 想快速拿药

就直接去 Notaufnahme，通常不是合适的做法。

德国医疗体系中，不同医疗服务承担不同任务。

普通问题可以先找 Hausarzt；非营业时间又需要医疗帮助，可以联系 116117。

## 十四、晚上或者周末生病怎么办？

如果 Hausarzt 已经关门，但你出现了需要医疗帮助的问题，可以联系 116117。

根据具体情况，可能会：

- 提供电话医疗建议
- 帮你寻找值班医生
- 建议前往 Bereitschaftsdienst
- 根据情况安排进一步医疗服务

如果情况危及生命，则直接拨打 112。

## 十五、儿童出现急症怎么办？

儿童出现严重症状时，也应该根据病情判断。

如果可能危及生命：

**112**

如果需要医疗帮助，但没有明显生命危险：

**116117**

如果需要医院紧急评估：

**Notaufnahme / 儿童急诊**

具体哪个医院提供儿童急诊，可以通过当地医院或 116117 查询。

## 十六、牙科急诊怎么办？

普通牙痛、蛀牙等问题通常应该联系 Zahnarzt。

如果在非营业时间出现严重牙科问题，可以查询当地的 zahnärztlicher Notdienst（牙科急诊服务）。

如果同时出现严重呼吸困难、意识丧失等可能危及生命的情况，则应该拨打 112。

详细内容见：

- [0008｜德国牙医 Dentist](0008_Dentist.md)

## 十七、德语不好怎么办？

如果需要拨打急救电话，可以直接说明：

“Notfall.”

然后告诉接线人员：

- 发生了什么
- 具体地址
- 目前情况
- 是否有人受伤
- 是否有人失去意识

如果不会用德语描述复杂症状，也可以先说：

“Ich spreche nicht gut Deutsch.”

然后尽量提供准确地址和基本情况。

## 十八、记住几个重要号码

**112**

紧急救援 / 可能危及生命的情况

**116117**

非生命危险的医疗帮助

**110**

警察紧急电话

医疗问题不要因为看到 110 和 112 都是紧急号码就混淆。

## 十九、最简单的判断方法

可以先问自己：

**这是普通的小病吗？**

→ Hausarzt / 正常医疗预约

**需要医疗帮助，但可以等待一段时间吗？**

→ Hausarzt / Facharzt / 116117

**现在就需要医院紧急处理吗？**

→ Notaufnahme

**可能危及生命吗？**

→ 112

如果自己无法判断，而症状又比较严重，不要单纯依靠网络搜索判断是否安全等待，可以寻求专业医疗帮助。
