# 0010｜德国专科医生与转诊 Specialist Appointments and Referrals

在德国看病时，如果 Hausarzt 发现问题需要进一步检查，可能会让你去 Facharzt（专科医生）。

德国的专科预约和中国的“挂哪个科”有些不同。有些 Facharzt 可以直接预约，有些情况下则可能需要 Überweisung（转诊）。

## 一、什么是 Facharzt？

Facharzt 就是专科医生。

常见的 Facharzt 包括：

- Hautarzt：皮肤科
- Frauenarzt：妇科
- HNO-Arzt：耳鼻喉科
- Augenarzt：眼科
- Orthopäde：骨科
- Kardiologe：心脏科
- Neurologe：神经科
- Gastroenterologe：消化科
- Urologe：泌尿科
- Endokrinologe：内分泌科

如果你已经知道自己的问题属于哪个专科，可以直接寻找对应的 Facharzt。

如果完全不知道应该看哪个科，也可以先找 Hausarzt。

## 二、一定要先看 Hausarzt 吗？

**不一定。**

德国并不是所有专科都要求先经过 Hausarzt。

很多 Facharzt 可以直接预约。

例如：

**有皮肤问题 → 可以直接联系 Hautarzt**

**牙齿问题 → 直接联系 Zahnarzt**

**眼睛问题 → 可以联系 Augenarzt**

但某些医疗情况可能更适合先由 Hausarzt 进行初步判断。

Hausarzt 可以根据症状决定：

- 是否需要专科
- 应该看哪个专科
- 是否需要进一步检查
- 是否需要 Überweisung

## 三、什么是 Überweisung？

Überweisung 就是医生给你的转诊。

例如：

**Hausarzt → Überweisung → Kardiologe**

或者：

**Hausarzt → Überweisung → Neurologe**

转诊通常会说明需要专科进一步处理的医疗问题。

但要注意：

**有 Überweisung ≠ 所有 Facharzt 都必须接受你。**

具体预约方式和要求要看专科诊所。

## 四、什么时候可能需要 Überweisung？

是否需要 Überweisung，取决于具体医生、专科和医疗情况。

有些 Facharzt 可以直接预约，不需要转诊。

有些情况下，医生可能要求：

- Überweisung
- Arztbrief
- Befunde
- 其他医疗资料

因此预约时可以直接问：

“Brauche ich eine Überweisung?”

如果对方要求转诊，再联系 Hausarzt。

## 五、怎么找 Facharzt？

可以使用：

- Google Maps
- Doctolib
- 116117
- Krankenkasse 的医生搜索
- 医生诊所官网

搜索时可以使用：

“Hautarzt München”

“Neurologe Berlin”

“Orthopäde Hamburg”

也可以直接搜索具体专科名称。

## 六、预约专科时要问什么？

打电话或者网上预约时，可以确认：

- 是否接受新患者
- 是否需要 Überweisung
- 是否接受你的 Krankenkasse
- 最近什么时候有 Termin
- 第一次就诊需要带什么
- 是否需要提前准备检查结果

例如：

“Behandeln Sie neue Patienten?”

“Brauche ich eine Überweisung?”

“Welche Unterlagen soll ich mitbringen?”

## 七、为什么 Facharzt 经常很难预约？

德国一些专科医生的预约等待时间可能比较长。

尤其是：

- 热门专科
- 大城市
- 新患者
- 某些紧缺专科

所以不要只联系一家诊所。

可以同时寻找：

- 不同诊所
- 不同地区
- 不同预约平台
- 116117 提供的医疗服务

如果医生明确告诉你需要尽快看专科，也可以让 Hausarzt 根据具体情况提供进一步建议。

## 八、116117 可以帮助找专科吗？

116117 不只是一个电话医疗咨询服务。

它还提供医生和医疗服务相关的信息，在部分情况下可以帮助寻找合适的医疗服务或预约。

如果普通 Facharzt 很难预约，可以尝试使用 116117 的相关服务。

但具体能否预约到医生，要看当地资源和医生是否提供相应服务。

## 九、急性问题和普通专科预约不一样

如果你有一个已经存在一段时间、但并不紧急的问题，可以正常预约 Facharzt。

例如：

- 长期皮肤问题
- 慢性关节疼痛
- 长期胃部不适
- 一般性的视力问题

但如果症状突然严重或者快速恶化，就不应该只是等待几周后的 Facharzt Termin。

这种情况下可以联系 Hausarzt、116117，或者根据严重程度前往 Notaufnahme / 拨打 112。

详细内容见：

- [0009｜德国医疗急诊 Emergency](0009_Emergency.md)

## 十、第一次去 Facharzt 要带什么？

建议准备：

- Gesundheitskarte
- 身份证件
- Überweisung（如果需要）
- 以前的检查报告
- X 光、CT、MRT 等检查结果
- Arztbrief
- 当前服用的药物
- 过敏信息

如果是从 Hausarzt 转过去，最好把 Hausarzt 给你的相关资料一起带上。

## 十一、什么是 Arztbrief？

Arztbrief 是医生之间用于传递医疗信息的医学报告。

例如：

Hausarzt → Facharzt

或者：

Krankenhaus → Hausarzt

Arztbrief 中可能包含：

- 诊断
- 检查结果
- 治疗经过
- 药物
- 后续治疗建议

如果医院或者专科医生给了你 Arztbrief，最好保存下来。

## 十二、专科医生可能会做什么？

第一次就诊时，Facharzt 可能会：

- 询问病史
- 了解当前症状
- 查看以前的检查结果
- 进行专科检查
- 安排进一步检查
- 给出治疗建议
- 开药
- 建议复诊

具体内容取决于专科和你的症状。

## 十三、需要做检查怎么办？

Facharzt 可能会安排：

- Blutuntersuchung：血液检查
- Ultraschall：超声
- Röntgen：X 光
- MRT：磁共振
- CT：CT
- 其他专科检查

检查可能直接在诊所完成，也可能需要去其他医疗机构。

如果检查需要另外预约，医生或诊所通常会告诉你下一步怎么做。

## 十四、检查结果出来以后怎么办？

检查完成后，可能需要：

- 回到 Facharzt 复诊
- 由 Hausarzt 继续跟进
- 根据结果进行治疗
- 转到其他专科
- 进一步检查

如果检查是在其他机构完成的，要注意检查结果如何传回给医生。

不要默认所有医生之间都会自动拥有你的完整医疗资料。

## 十五、可以直接换 Facharzt 吗？

如果对当前医生不满意，通常可以寻找其他医生。

例如：

- 预约太难
- 沟通困难
- 想听取第二个意见
- 希望寻找其他专科医生

如果涉及已经开始的治疗，最好把之前的检查结果、Arztbrief 等资料带给新医生。

## 十六、什么是 Zweitmeinung？

Zweitmeinung 就是第二诊疗意见。

如果面对比较重要的诊断或治疗决定，例如：

- 手术
- 长期治疗
- 某些复杂疾病

可以考虑向另一位医生询问意见。

但是否属于法定医保的正式 Zweitmeinungsverfahren，以及费用如何承担，要看具体情况。

## 十七、专科医生需要自己付钱吗？

如果你参加 GKV，并且接受的是医保保障范围内的正常医疗服务，通常不需要像私人患者一样支付全部费用。

但以下情况可能产生费用：

- IGeL-Leistung
- Selbstzahlerleistung
- 不属于医保保障范围的服务
- 某些法定 Zuzahlung

如果医生告诉你需要付费，可以先问：

“Wird das von meiner Krankenkasse übernommen?”

“Wie viel muss ich selbst bezahlen?”

## 十八、如果专科医生不接受新患者怎么办？

这种情况并不少见。

可以尝试：

- 联系其他 Facharzt
- 使用 Doctolib 等预约平台
- 使用 116117
- 联系 Krankenkasse
- 询问 Hausarzt 是否可以推荐其他医生
- 扩大搜索范围

如果只是为了找到一个长期固定的专科医生，不一定非要选择离家最近的一家。

## 十九、不同专科的预约方式可能不同

并不是所有 Facharzt 都有完全一样的预约规则。

例如：

- 有的可以直接网上预约
- 有的只接受电话预约
- 有的要求 Überweisung
- 有的暂时不接受新患者
- 有的只提供特定时间段的 Akutsprechstunde

所以预约前最好直接确认诊所的要求。

## 二十、专科就诊最简单的流程

可以理解为：

**出现问题 → Hausarzt 或直接寻找 Facharzt**

如果需要转诊：

**Hausarzt → Überweisung → Facharzt → 检查 / 治疗**

如果需要进一步检查：

**Facharzt → Untersuchung → Befund → 后续治疗**

如果情况突然严重：

**116117 / Notaufnahme / 112**

具体选择取决于症状的严重程度。
