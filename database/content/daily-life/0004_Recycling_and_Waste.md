# ♻️ Recycling and Waste｜德国垃圾分类与回收指南

德国有比较统一的垃圾分类框架，但具体使用什么垃圾桶、在哪里投放，以及部分垃圾的收集方式，会因城市和地区而异。

因此，分类时先判断垃圾的种类，再查询当地的 **Abfall-ABC（垃圾分类查询目录）**，不要只依赖垃圾桶颜色。

## 1. 🗑️ 德国常见垃圾分类

德国日常生活中最常见的垃圾类别：

| 德语 | 中文 | 典型垃圾 |
|---|---|---|
| Restmüll | 普通生活垃圾 | 用过的纸巾、烟头、无法回收的脏污垃圾 |
| Biomüll | 有机垃圾 | 果皮、菜叶、食物残渣 |
| Altpapier | 废纸 | 报纸、纸箱、干净纸张 |
| Verpackungsabfälle | 包装垃圾 | 塑料、金属、复合材料包装 |
| Altglas | 废玻璃包装 | 玻璃瓶、果酱瓶 |
| Sperrmüll | 大件垃圾 | 沙发、床、柜子 |
| Elektroaltgeräte | 废旧电子电器 | 手机、电脑、小家电 |
| Batterien | 电池 | AA、AAA、电池组 |
| Problemstoffe / Sonderabfälle | 有害及特殊垃圾 | 油漆、溶剂、部分化学品 |
| Pfand | 押金包装 | 符合押金制度的饮料瓶和罐 |

## 2. Restmüll｜普通生活垃圾

Restmüll 指经过分类后，无法进入其他回收系统的普通生活垃圾。

常见例子：

- 使用过的纸巾、卫生纸
- 脏污严重的厨房纸
- 烟头
- 吸尘器灰尘
- 无法回收的日常小垃圾

注意，以下物品不能因为不确定怎么分类就直接扔进 Restmüll：

- 电池和蓄电池
- 废旧电子产品
- 应单独收集的包装
- 玻璃包装
- 有害化学品

## 3. Biomüll｜有机垃圾

Biomüll 主要收集适合生物处理的厨房和园林有机垃圾。

常见包括：

- 水果和蔬菜残渣
- 果皮、菜叶
- 咖啡渣和咖啡滤纸
- 茶叶
- 鸡蛋壳
- 剩余食物
- 花草、落叶和部分园林垃圾

**肉类、鱼类、熟食是否可以投入，要看当地规定。** 例如慕尼黑 AWM 允许生熟肉类和鱼类残渣进入 Biotonne。

通常不应投入：

- 塑料包装
- 普通塑料袋
- 宠物粪便和猫砂等不符合当地规定的宠物废弃物

部分地区不接受标注为可堆肥的塑料垃圾袋，不能因为包装写着 biologisch abbaubar 就默认可以投入。

慕尼黑的具体规定可以查询 AWM 的 [Abfall-ABC](https://www.awm-muenchen.de/)，其他城市则应查询当地垃圾处理机构。

## 4. Altpapier｜废纸、纸板和纸箱

一般可以回收：

- 报纸和杂志
- 普通纸张
- 信件和文件
- 纸盒
- 网购纸箱
- 干净的纸质包装

以下物品通常不属于废纸回收：

- 使用过的纸巾
- 湿纸巾
- 油污严重的纸张
- 热敏纸收据（Thermopapier）
- 照片及部分特殊涂层纸

纸箱投放前最好压扁或拆开，减少占用空间。

## 5. Verpackungsabfälle｜包装垃圾

包装垃圾是德国分类中最容易混淆的部分。

全国基本规则是：

| 包装材料 | 一般投放位置 |
|---|---|
| 纸、纸板、纸箱包装 | Altpapier |
| 玻璃包装 | Altglas |
| 塑料包装 | Gelbe Tonne / Gelber Sack |
| 金属包装 | Gelbe Tonne / Gelber Sack |
| 复合材料包装 | Gelbe Tonne / Gelber Sack |

部分地区使用 **Wertstofftonne**，除了包装，还可能允许投入与包装同材质的部分非包装物品，例如某些塑料或金属制品。

需要注意，Gelbe Tonne、Gelber Sack 和 Wertstofftonne 并不是完全相同的收集系统，不能直接互换。

### Gelbe Tonne

黄色垃圾桶，主要收集塑料、金属和复合材料包装。

### Gelber Sack

黄色垃圾袋，收集种类通常与当地黄色包装垃圾系统相同，只是使用垃圾袋而不是固定垃圾桶。

### Wertstofftonne

可回收物垃圾桶。部分地区不仅收集包装，也允许投入特定的非包装塑料和金属物品。

例如，某些地区允许将损坏的平底锅或塑料桶投入 Wertstofftonne，但不代表德国所有城市都允许这样做。

## 6. 包装垃圾怎么处理？

常见属于黄色收集系统的包装：

**塑料包装**
- 酸奶杯
- 塑料食品盒
- 塑料薄膜
- 塑料袋
- 塑料包装瓶

**金属包装**
- 罐头盒
- 铝箔
- 金属瓶盖
- 铝制食品包装

**复合包装**
- 牛奶盒
- 果汁盒
- Tetra Pak 饮料纸盒

投放前注意：

1. 包装应该倒空，不需要彻底清洗。
2. 如果不同材料可以轻松分离，应尽量拆开，例如酸奶杯和铝膜盖。
3. 不要把不同包装套在一起，尽量分开投放。
4. 电子产品即使含有塑料，也不能作为普通塑料包装处理。

德国联邦环境署建议，包装倒空即可，通常不需要为了回收专门冲洗。<Cite refs={["turn675161search6","turn675161search8"]}/>

## 7. Altglas｜废玻璃包装

Altglas 主要指玻璃包装，例如：

- 果酱瓶
- 玻璃食品瓶
- 不属于 Pfand 系统的玻璃饮料瓶
- 其他玻璃包装容器

公共玻璃回收箱通常按照颜色分类：

- **Weißglas**：白玻璃
- **Braunglas**：棕色玻璃
- **Grünglas**：绿玻璃

蓝色、红色等其他颜色的玻璃，通常投入 Grünglas。

### 不是所有玻璃都能扔进 Altglas

以下物品通常不能进入玻璃包装回收箱：

- 玻璃杯
- 镜子
- 窗玻璃
- 陶瓷
- 瓷器
- 耐热玻璃

原因是这些材料的成分和熔化特性不同，可能影响玻璃包装的回收质量。

另外，属于 Pfand 系统的饮料瓶应优先退回商店，而不是直接投入 Altglas。<Cite refs={["turn675161search2","turn675161search6","turn675161search14"]}/>

## 8. Pfand｜押金瓶和罐

Pfand 是德国饮料包装押金制度，不属于普通垃圾分类。

购买符合押金制度的饮料时，需要额外支付押金，退回符合要求的空瓶或空罐后可以取回。

常见标识包括：

- Einweg：一次性包装
- Mehrweg：可重复使用包装
- Pfand：押金

具体退瓶方式、金额和适用范围可以查看：

`daily-life/0008_Pfand.md`

## 9. Sperrmüll｜大件垃圾

Sperrmüll 指无法正常投入普通生活垃圾桶的家庭大型废弃物。

例如：

- 沙发
- 床
- 衣柜
- 桌椅
- 大型家具

处理方式由当地规定，可能包括：

- 预约上门收集
- 指定日期集中收集
- 自行送到 Wertstoffhof
- 按规定支付处理费用

注意，电子产品、建筑垃圾和某些特殊材料不能因为体积大就全部算作 Sperrmüll。

如果要扔家具，先查询当地 Sperrmüll 规定，不要随意放在住宅楼旁边或公共区域。

## 10. Elektroaltgeräte｜废旧电子电器

电子电器不能直接扔进 Restmüll 或普通包装垃圾桶。

常见包括：

- 手机
- 电脑
- 显示器
- 电水壶
- 吹风机
- 小型厨房电器
- 电动工具

常见回收渠道：

- **Wertstoffhof**：市政回收站
- 电子产品零售商提供的回收服务
- 当地指定的电子垃圾回收点

如果设备内含电池，且电池可以安全拆卸，应按照规定分别处理。手机、电脑等设备在丢弃前还应删除个人数据。

## 11. Batterien｜电池

电池和蓄电池不能直接扔进普通垃圾桶。

例如：

- AA / AAA 电池
- 充电电池
- 纽扣电池
- 部分电子设备电池

常见回收地点：

- 超市
- 电子产品商店
- 电池回收箱
- Wertstoffhof

如果是鼓包、破损或漏液的锂电池，不要直接投入普通电池回收箱，应联系回收点确认安全交付方式。

## 12. Problemstoffe / Sonderabfälle｜有害及特殊垃圾

部分家庭废弃物需要特殊处理，不能直接进入 Restmüll 或下水道。

例如：

- 油漆和涂料
- 溶剂
- 部分化学清洁剂
- 有害化学品
- 某些含危险成分的产品

常见处理渠道：

- Problemstoffsammlung
- Schadstoffmobil
- Wertstoffhof
- 当地指定的 Sonderabfall-Sammelstelle

不同城市接收的物品和开放时间可能不同。遇到不确定的化学品，不要直接混合或倒入下水道，应先查询当地处理要求。

## 13. 🏙️ 慕尼黑的垃圾分类：2026 和 2027 年的区别

慕尼黑的包装垃圾收集系统正在发生变化，因此需要特别区分两个时间段。

<badge color="info">截至 2026 年底</badge>

慕尼黑目前常规系统主要通过 **Wertstoffinseln（可回收物集中投放点）** 收集销售包装。

通常可以在那里投放：

- 玻璃包装
- 塑料包装
- 金属包装
- 饮料纸盒等复合包装

投放前需要将包装倒空，不必彻底清洗；不同材料应尽量分开。

部分城区参加了 2024—2026 年的试点项目，使用 Gelbe Tonne、Gelber Sack 或 Wertstofftonne。因此，试点区域应按照自己所在区域的规定投放。<Cite refs={["turn675161search3","turn675161search4","turn675161search11"]}/>

<badge color="success">从 2027 年开始</badge>

慕尼黑已决定全市引入 **Gelbe Tonne**，用于收集塑料、金属和复合材料销售包装。

目前公布的主要安排：

- 全市范围内引入 Gelbe Tonne。
- 垃圾桶容量包括 120 L、240 L、770 L 和 1,100 L。
- 原则上每两周清运一次。
- 预计从 2027 年 1 月开始正式清运。
- 玻璃回收箱仍保留在 Wertstoffinseln。

截至 2026 年 11 月，负责收集的企业和东西部区域联系方式已经公布，具体投放和清运安排可以通过 AWM 查询。<Cite refs={["turn675161search0","turn675161search1","turn675161search9"]}/>

**特别注意：** 2026 年底之前不要因为看到黄色垃圾桶就默认它已经开始正式清运。按照当地通知使用现有系统，等待 2027 年正式启用。

## 14. 🔎 Abfall-ABC｜不知道垃圾该扔哪里怎么办？

日常生活中，最常遇到的问题是：一个具体物品到底属于哪种垃圾？

这时可以搜索：

**城市名称 + Abfall-ABC**

例如：

- München Abfall-ABC
- Berlin Abfall-ABC
- Hamburg Abfall-ABC

在当地垃圾分类查询页面输入物品名称，例如：

- Pfanne：平底锅
- Joghurtbecher：酸奶杯
- Batterie：电池
- Elektrogerät：电子设备
- Karton：纸箱
- Glas：玻璃
- Katzenstreu：猫砂

通常就能找到对应的投放方式。

## 15. 🏠 搬家后应该确认什么？

不同城市的垃圾收集系统可能不同。搬家后建议确认：

1. Restmüll 和 Biomüll 垃圾桶在哪里？
2. Altpapier 应该投放到哪里？
3. 包装垃圾使用 Gelbe Tonne、Gelber Sack 还是 Wertstofftonne？
4. Altglas 回收点在哪里？
5. Sperrmüll 如何预约？
6. Elektroaltgeräte 和 Batterien 去哪里回收？
7. 当地 Abfall-ABC 在哪里？
8. 垃圾桶的清运日期是什么时候？

德国很多住宅楼会有固定的垃圾桶区域（Mülltonnenstandplatz），可以向房东或 Hausverwaltung 询问具体位置和使用规定。

## 🔗 官方查询入口

- **Umweltbundesamt（德国联邦环境署）**：<https://www.umweltbundesamt.de/>  
  查询德国垃圾分类、包装回收和环保规定。

- **Zentrale Stelle Verpackungsregister（中央包装登记机构）**：<https://www.verpackungsregister.org/>  
  查询德国包装回收制度及相关规定。

- **AWM München（慕尼黑垃圾处理机构）**：<https://www.awm-muenchen.de/>  
  查询慕尼黑垃圾分类、Abfall-ABC、Wertstoffhof、Wertstoffinseln 和 Gelbe Tonne。

## 📝 OMA 小结

德国垃圾分类不只是记住垃圾桶的颜色，而是先判断垃圾的材料和性质，再按照当地收集系统处理。

尤其记住几个容易混淆的地方：

- 包装垃圾不等于所有塑料制品。
- Altglas 主要收集玻璃包装，不是所有玻璃制品。
- 电池和电子产品必须单独处理。
- Pfand 瓶罐应优先退回商店。
- Gelbe Tonne、Gelber Sack 和 Wertstofftonne 的具体适用范围要看当地规定。

**最实用的方法：不确定时，查询所在城市的 Abfall-ABC，而不是随便找一个垃圾桶投进去。**
