# Germany OS 产品生态

Germany OS 并不是一个网站。

而是由多个产品组成。

包括：

- 小红书
- Website
- Germany Database
- AI
- PDF
- 工具
- Newsletter（未来）

---

定位：

Germany OS 的核心资产。

作用：

- 存储所有知识
- 网站内容来源
- AI知识来源

★★★★★

# Germany OS 产品原则

每开发一个产品，都必须满足：

- 能复用 Germany Database
- 能长期使用
- 能帮助用户
- 能形成资产
- 能产生商业价值

否则暂缓开发。
